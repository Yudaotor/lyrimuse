常见问题。

没找到你想问的？

到 GitHub 提问
支持哪些 Mac？

macOS 14 Sonoma 及以上，Apple Silicon 和 Intel 都支持，Intel 用单独的安装包。想在本机翻译歌词，需要 macOS 15 及以上。

怎么安装？

推荐用 Homebrew：点上面的「复制 Homebrew 安装命令」，粘到终端运行，第一次打开时的 Gatekeeper 提示它会顺手处理，也不需要 Apple 开发者账号。也可以下载 DMG，把 Lyrimuse 拖进「应用程序」。App 没有经过 Apple 公证，第一次打开会被系统拦下：打开「系统设置 → 隐私与安全性」，滚到最底部点「仍要打开」，只需要这一次。之后的更新都在 App 里完成。大陆下载慢的话，可以在下载地址前加 https://ghfast.top/ 这类加速前缀。

需要给哪些权限？

Apple Music、Spotify 和 Kaset 第一次使用时，macOS 会问你要不要允许 Lyrimuse 控制它们（「自动化」权限），同意就行；其他播放器显示歌词不用额外授权。「辅助功能」权限可选：开了以后，部分播放器的喜欢、随机和循环键会出现在歌词窗口里，浏览器视频占着播放键时，也照样能控制 QQ 音乐、网易云音乐和汽水音乐。

我的数据会上传吗？

没有账号、没有遥测、没有统计，关于你和你听什么，不会有任何信息发到开发者那里。找歌词时会把正在放的这首歌拿去问各个歌词源，翻译默认在本机完成。完整清单见隐私政策。

没有网络能看歌词吗？

能。找过一次的歌词会存在本机，之后不联网也能显示；第一次找歌词和联网翻译需要网络。

没有刘海的 Mac 能用灵动岛吗？

能。在没有刘海的屏幕上（老款 MacBook 或外接显示器），胶囊贴在屏幕顶部居中，跟菜单栏一样高，放在哪块屏幕可以在设置里选。

歌词不对或者不同步怎么办？

时间对不上，就给这首歌调个偏移，之后会一直记住；版本不对，就打开手动搜索换一份，选中的那份会被锁定。也可以在「歌词管理」里直接改。

和 LyricsX 有什么区别？

LyricsX 最后一个版本是 2022 年 4 月的 v1.6.3。Lyrimuse 需要 macOS 14 以上，多支持了 QQ 音乐、网易云音乐、酷狗、汽水音乐、KKBOX、Amazon Music、YouTube Music、洛雪音乐和 reAMP，歌词按打分挑选，有粤拼和日文罗马音，还能记录到 Last.fm。详见逐项核实的对比。

下载开始了，还差两步

没开始下载？ 再点一次

  1. 把 Lyrimuse 拖进 Applications

    打开下载好的 .dmg，把 Lyrimuse 拖到旁边的 Applications 文件夹上。

    Lyrimuse Applications

  2. 第一次打开时放行一次

    第一次打开会被系统拦下，先点「完成」。再打开「系统设置 → 隐私与安全」，滚到最下面，点「仍要打开」并确认。之后就能正常打开了。

    安全性已阻止“Lyrimuse”以保护Mac。仍要打开

提示「已损坏，无法打开」，或者找不到「仍要打开」？在终端里运行：

xattr -dr com.apple.quarantine /Applications/Lyrimuse.app
