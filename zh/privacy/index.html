隐私政策

最后更新：2026 年 10 月 4 日

一句话版：Lyrimuse 没有账号体系、没有遥测、没有统计，开发者也没有接收 App 数据的服务器。找歌词得拿正在放的这首歌去问各个歌词源，所以 App 会联系第三方服务。本页把它们全部列出来。

1适用范围

本政策适用于 Lyrimuse macOS 应用、随 App 一起安装的歌词引擎，以及 yudaotor.github.io/lyrimuse 这个网站。Lyrimuse 是一个由个人开发者（Yudaotor）维护的开源项目，背后没有公司。

2我们收集什么：什么都不收

没有注册、没有用户 ID、没有崩溃上报、没有使用统计。开发者不运营任何接收 App 数据的服务器，所以手上没有任何关于你的数据，也就没有什么可以给你导出、更正或删除。

源代码是公开的，这件事你可以自己去核，不必只听我说。

3留在你 Mac 上的东西

App 记住的一切都写在你自己的 Mac 上，主要在 ~/.config/lyrimuse 下：

  • 你的设置
  • 歌词缓存，所以听过一次的歌离线也能显示
  • 本机听歌历史，榜单和「那年今日」就是从它算出来的
  • 你主动连接的服务的凭据，比如 Last.fm 的 session key 或 ListenBrainz 的 token
  • 下文说的对外请求日志

这些都不会上传。删掉那个文件夹就没了；随附的 uninstall.sh --purge 会连同其它文件一起删掉。

4App 会联系哪些服务器

除了表里写明的账号凭据，这些请求都不附带任何能标识你或你这台 Mac 的信息。对方能看到的是请求本身，以及你的 IP 地址，这跟你打开一个网站是一回事。

5对外请求日志

App 发出的每一次网络请求都会记进你 Mac 上的一份日志。它只记服务名、操作、域名、HTTP 状态码和耗时，从不记完整地址、参数、请求内容或任何凭据。

你可以在「控制台」里看这份日志，也可以在设置里导出诊断信息时带上它。导出永远是你手动操作的，文件存在哪儿由你决定。

6App 申请的权限

  • 「自动化」：选了 Apple Music 或 Spotify 时，用来读取正在播放的曲目和进度、发送播放控制。在浏览器里听歌并打开「网页播放器进度」时，也会请求对该浏览器的「自动化」，用来读网页上播放器的真实进度。
  • 「完全磁盘访问」，可选：QQ 音乐、网易云音乐、酷狗把播放队列放在受系统保护的文件夹里。授权后，Lyrimuse 能提前给接下来要放的歌找好歌词；不授权只是少了这一步。

其它播放器读的是系统的「正在播放」信息，不需要权限。这些权限只用于跟随你正在放的歌，没有别的用途。

7这个网站

这些页面是托管在 GitHub Pages 上的静态文件，没有 cookie、没有统计脚本、没有任何追踪。页面只会在你自己浏览器的本地存储里记一项你选的语言。打开下载菜单时，页面会向 GitHub API 查一次最新版本号。GitHub 作为托管方会像任何 Web 服务器一样记录请求，详见 GitHub 的隐私声明。

8未成年人

Lyrimuse 不面向儿童，也不收集任何年龄段任何人的个人数据。

9变更

App 的数据行为有变化时，本页会跟着改，顶部日期也会更新。本页的修改历史在仓库里是公开的。
