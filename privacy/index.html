Privacy Policy

Last updated 4 October 2026

Short version: Lyrimuse has no account system, no telemetry and no analytics, and the developer runs no server that receives anything from the app. Finding lyrics means asking lyric sources about the song that's playing, so the app does contact third-party services. This page lists every one of them.

1Who this covers

This policy covers the Lyrimuse macOS app, the lyrics engine that ships inside it, and this website at yudaotor.github.io/lyrimuse. Lyrimuse is an open-source project kept by one developer (Yudaotor). There is no company behind it.

2What we collect: nothing

There is no sign-up, no user ID, no crash reporter and no usage analytics. The developer runs no server that receives data from the app, so there is no data about you to export, correct or delete.

The source code is public, so this is something you can check rather than take on trust.

3What stays on your Mac

Everything the app remembers is written to your own Mac, mainly under ~/.config/lyrimuse:

  • your settings
  • the lyrics cache, so a song you have played once also works offline
  • your local listening history, which the charts and On This Day are built from
  • credentials for services you chose to connect, such as a Last.fm session key or a ListenBrainz token
  • the outbound request log described below

None of it is uploaded. Delete that folder and it's gone; the bundled uninstall.sh --purge removes it along with everything else.

Apart from the account credentials listed in the tables, none of these requests carries anything that identifies you or your Mac. Each service sees the request itself and, as with any website, your IP address.

5The outbound request log

Every network request the app makes is written to a log on your Mac. It records the service, the operation, the hostname, the HTTP status and how long it took, and never the full address, the parameters, the body or any credential.

You can read it in Console.app, or include it in a diagnostics export from Settings. Exporting is always something you do by hand, and the file goes wherever you save it.

6Permissions the app asks for

  • Automation, for Apple Music and Spotify when you pick them: it reads the current track and position and sends play controls. If you listen in a browser and turn on accurate web player progress, it also asks for Automation over that browser, to read the player's real position on the page.
  • Full Disk Access, optional: QQ Music, NetEase Cloud Music and Kugou keep their play queue in a protected folder. With access, Lyrimuse finds lyrics for the songs coming up next ahead of time; without it, that step is simply skipped.

Other players are read through the system's Now Playing information and need no permission. None of these permissions are used for anything but following what you play.

7This website

These pages are static files on GitHub Pages, with no cookies, analytics or trackers. The only thing they store is the language you pick, in your own browser's local storage. When you open the download menu, the page asks the GitHub API for the latest version number. GitHub, as the host, logs requests the way any web server does; see GitHub's privacy statement.

8Children

Lyrimuse is not directed at children and collects no personal data from anyone, of any age.

9Changes

When the app's data behaviour changes, this page changes with it and the date at the top is updated. Its history is public in the repository.
