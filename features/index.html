Every feature and setting

Lyrimuse v1.10.0, released October 2026

Lyrimuse is an open-source (GPL-3.0) Mac app for word-by-word synced lyrics, for macOS 14 or later on Apple Silicon and Intel. It shows lyrics for Apple Music, Spotify, QQ Music, NetEase Cloud Music, Kugou, Soda Music, KKBOX, Amazon Music, Kaset, and YouTube Music or Spotify Web playing in a browser: floating on the desktop, beside the notch, in the menu bar, on the Touch Bar or in a full lyrics window, with translations and romanization (pinyin, Cantonese Jyutping, Japanese romaji, Korean romanization). It scrobbles to Last.fm and ListenBrainz and can show what you play on Discord. The interface is in English, Simplified Chinese and Traditional Chinese.

This page lists every Lyrimuse feature: what it does, where it lives in Settings and whether it is on after you install, followed by every setting in the Settings window. The same list is on GitHub as Markdown.

2 Finding lyrics

Twelve lyric sources, searched for you

NetEase Cloud Music, QQ Music, Kugou, Kuwo, Migu, Musixmatch, LRCLIB, LyricFind, Deezer, AMLL, Soda Music and Apple Music. Each source can be turned off, reordered, or tested to see whether it is reachable right now.

  • On by default
  • Settings: Lyrics › Sources › Lyrics Sources

Apple Music's own lyrics

Connect your Apple Music account under Lyrics Sources to use Apple Music's own lyrics, many of them timed word by word. Needs an Apple Music subscription.

  • Off by default
  • Settings: Lyrics › Sources › Lyrics Sources

Smart matching

By default every result is scored on title, artist, length and version (live, instrumental and so on), and the best fit for the song that is playing wins. You can switch to source order instead: no scoring, the first source in your order that has lyrics is used.

  • Settings: Lyrics › Sources › Matching Algorithm

Re-pick lyrics when matching improves

When a new version improves matching or scoring, lyrics you already have are re-checked in the background and replaced if a better version turns up. Turn it off to keep lyrics once they are chosen.

  • On by default
  • Settings: Lyrics › Sources › Re-Pick After Algorithm Updates

Lyrics ready before the next song

Reads your player's queue and finds lyrics for the next few songs ahead of time; when there is no queue to read, it works through the rest of the album. QQ Music, NetEase Cloud Music and Kugou need Full Disk Access for this.

  • On by default
  • Settings: Lyrics › Sources › Pre-Resolve Upcoming Tracks
  • Settings: Player › Full Disk Access

Use the lyrics your player already saved

Lyrics that QQ Music, NetEase Cloud Music and Kugou already downloaded can be used directly: the same version the player shows, and faster. This needs Full Disk Access for Lyrimuse in System Settings; without it lyrics are still found online.

  • Off by default
  • Settings: Player › Full Disk Access

Warns you when a lyric source misbehaves

When a lyric source has lately found almost nothing, far less than usual, or keeps failing or timing out, a warning appears next to it under Lyrics Sources; click it for the numbers behind it. The other sources keep searching, and the counting happens only on your Mac.

  • Settings: Lyrics › Sources › Lyrics Sources

Lock hand-picked lyrics

When on, lyrics you pick by hand from search results are locked, so later automatic matching and re-matching never replace them.

  • Off by default
  • Settings: Lyrics › Sources › Lock Hand-Picked Lyrics

Lyrics Manager

Browse, edit, delete or search again for any song's lyrics, delete in bulk, and clear out the empty entries ads and podcasts leave behind. Give a single song its own timing offset. Retry every song that has no lyrics yet in one go, or re-match the whole library under the current rules; anything you edited by hand is left alone.

  • Settings: Lyrics › Library › Lyrics Library
  • Settings: Lyrics › Library › Auto-Match Missing Lyrics
  • Settings: Lyrics › Library › Re-Match Whole Library
  • Settings: Keyboard Shortcuts › Open Lyrics Manager

Swap or fix lyrics on the spot

From the lyrics window's ⋯ menu, search for other lyrics, run matching again, or edit them in your own text editor. Editing word-timed lyrics changes only the words, never their timing.

  • Settings: Keyboard Shortcuts › Search Lyrics

Works offline; lyrics are plain .lrc files

Every lyric found is cached on your Mac and shows without a connection. Each song has an .lrc file, plus .tr.lrc and .roma.lrc for translations and romanization, and word timing in .yrc. They live in ~/.config/lyrimuse/lyrics/ by default, and the folder can be moved.

  • Settings: Lyrics › Library › Lyrics Folder

3 Translation, romanization and line handling

Translations

Translations that come with the lyrics appear under each line. NetEase Cloud Music, QQ Music and Kugou translate into Chinese; Musixmatch and machine translation follow the translation language you pick, from 17. Floating lyrics, the lyrics window, the notch, the menu bar and the Touch Bar each decide whether to show them. Shown by default when your Mac's languages include Chinese.

  • Settings: Lyrics › Translation › Translation Language
  • Settings: Lyrics Display › Floating Lyrics › Content › Translation
  • Settings: Keyboard Shortcuts › Show/Hide Translation

Machine translation when there is none

When no source has a translation, the lyrics are translated by machine. On macOS 15 or later with the language downloaded, Apple Translation does it on your Mac and the lyrics stay there; otherwise the lines to translate are sent to Google Translate, then MyMemory. Translation languages are downloaded from the same card.

  • Off by default
  • Settings: Lyrics › Translation › System Fallback Translation
  • Settings: Lyrics › Translation › Translation Languages

Romanization

Japanese romaji, Korean romanization, Mandarin pinyin and Cantonese Jyutping, word by word above the lyrics. Language is judged line by line, so a Japanese line inside a Chinese song is the only one marked. Choose which languages to mark here; with a Chinese interface, pinyin starts off. Each display decides whether to show them.

  • On by default
  • Settings: Lyrics › Adjust › Romanization Languages
  • Settings: Lyrics Display › Floating Lyrics › Content › Romanization
  • Settings: Keyboard Shortcuts › Show/Hide Romanization

Simplified or Traditional Chinese

Shows all Chinese lyrics in Simplified or Traditional characters, whatever language the app itself is in.

  • Settings: Lyrics › Adjust › Chinese Script

Split long lines, join short ones

Floating lyrics, the notch, the menu bar and the Touch Bar split lines too long for their width and join lines that flash by too quickly, each by its own width. The lyrics window keeps one line per line. Two separate switches.

  • Off by default
  • Settings: Lyrics › Adjust › Split Long Lines
  • Settings: Lyrics › Adjust › Join Short Lines

Timing offset

Move all lyrics earlier or later, optionally for one player only. Single songs get their own offset in the Lyrics Manager, and shortcuts can advance, delay or reset it on the fly.

  • Settings: Lyrics › Adjust › Timing Offset
  • Settings: Keyboard Shortcuts › Advance Lyrics
  • Settings: Keyboard Shortcuts › Delay Lyrics
  • Settings: Keyboard Shortcuts › Reset Lyrics Offset

4 Where lyrics appear and how they look

Desktop floating lyrics

Lyrics floating above every window, always on top, lit up word by word. Leave them wherever you drag them, or pin them to the top centre of the screen or just above the Dock. Romanization, translation and the next line can show alongside.

  • On by default
  • Settings: Lyrics Display › Floating Lyrics › Desktop Floating Lyrics
  • Settings: Lyrics Display › Floating Lyrics › Position
  • Settings: Lyrics Display › Floating Lyrics › Content › Next Line
  • Settings: Keyboard Shortcuts › Show/Hide Floating Lyrics

Notch lyrics

A Dynamic Island-style capsule beside the notch at the top of the screen; Macs without a notch and external displays get one too. Each side can show the title, artist, album, artwork, playback controls, or elapsed or remaining time, next to a moving audio wave. Hover to expand it for controls, a seekable progress bar and lyrics timing. During ads it counts down the time left.

  • Off by default
  • Settings: Lyrics Display › Notch › Notch Lyrics
  • Settings: Lyrics Display › Notch › Style
  • Settings: Lyrics Display › Notch › Display
  • Settings: Lyrics Display › Notch › Left Ear
  • Settings: Keyboard Shortcuts › Show/Hide Notch Lyrics

Menu bar lyrics

The current line right in the menu bar, scrolling when it is too long instead of being cut off. Add a second line for the next line, the translation or romanization.

  • Off by default
  • Settings: Lyrics Display › Menu Bar › Menu Bar Lyrics
  • Settings: Lyrics Display › Menu Bar › Layout › Second Line
  • Settings: Keyboard Shortcuts › Show/Hide Menu Bar Lyrics

Touch Bar lyrics

On a MacBook Pro with a Touch Bar, the current line scrolls along as it is sung, with optional artwork and playback controls.

  • Off by default
  • Settings: Lyrics Display › Touch Bar › Touch Bar Lyrics
  • Settings: Keyboard Shortcuts › Expand/Collapse Touch Bar Lyrics

Lyrics window

Full-page lyrics modelled on Apple Music's lyrics view: blurred artwork behind, the whole song scrolling to the current line, duets split by singer, background vocals on their own line, held notes that swell and glow. The background can follow the artwork or be solid, a gradient or frosted glass. Open it from the menu bar icon or a shortcut.

  • Settings: Lyrics Display › Lyrics Window › Lyrics Window
  • Settings: Lyrics Display › Lyrics Window › Background › Background
  • Settings: Keyboard Shortcuts › Open Lyrics Window

Mini lyrics window

The lyrics window shrunk to a small card: just the current line, the current and next line, or a full scrolling page. Background, text colour, font, weight, sung colour and the title, artwork and time at the top are all set separately.

  • Settings: Lyrics Display › Lyrics Window › Layout › Lyrics Layout
  • Settings: Keyboard Shortcuts › Switch Mini / Full Size

Animated artwork

Albums with animated artwork on Apple Music move in the full-size lyrics window too. It pauses in Low Power Mode or with Reduce Motion on.

  • On by default
  • Settings: Lyrics Display › Lyrics Window › Artwork › Animated Artwork

Listening overview between songs

When nothing is playing, the lyrics window shows the last song with a line from its lyrics and a Resume button. With Last.fm connected it also shows how much you listened today, in the last 7 days and in total, a 30-day trend, On This Day and your recent plays with artwork.

Your look

Font (the system's, or your own .ttf / .otf), size, weight, text and background colours, outline and frosted glass. Floating lyrics come with colour themes and can save your own; text colour can follow the album artwork.

  • Settings: Lyrics Display › Floating Lyrics › Theme › Color Theme
  • Settings: Lyrics Display › Floating Lyrics › Theme › My Themes
  • Settings: Lyrics Display › Floating Lyrics › Text › Font
  • Settings: Lyrics Display › Floating Lyrics › Background › Frosted Glass Background

Word-by-word karaoke fill

Each word lights up as it is sung. Floating lyrics, the notch, the menu bar, the Touch Bar and the mini lyrics window each have their own switch; off means the whole line lights at once.

  • On by default
  • Settings: Lyrics Display › Floating Lyrics › Text › Karaoke Effect
  • Settings: Lyrics Display › Notch › Lyric Row › Karaoke Effect
  • Settings: Lyrics Display › Menu Bar › Color › Karaoke Effect

Line transition

When floating lyrics move to the next line, the old line slides up and the new one follows, instead of swapping in place.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Layout › Line Transition

Fade when the pointer is over it

Floating lyrics turn see-through while the pointer is over them, so they never block what is underneath. The mini lyrics window has its own switch.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Fade on Hover
  • Settings: Lyrics Display › Lyrics Window › Behavior › Fade on Hover

Lock position, long-press to drag

Lock floating lyrics in place, or require a long press before dragging so they never move by accident.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Lock Position
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Long-Press to Drag
  • Settings: Keyboard Shortcuts › Lock/Unlock Position

Controls on hover

Pointing at floating lyrics brings up a row of quick buttons. Menu bar lyrics can show playback controls on hover too.

  • On by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Controls on Hover
  • Settings: Lyrics Display › Menu Bar › Behavior › Show Controls on Hover

Hidden from screenshots and screen sharing

Screenshots, recordings and shared screens leave the lyrics out while you still see them. Floating lyrics and the notch each have a switch.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Hide in Screenshots
  • Settings: Lyrics Display › Notch › Behavior › Hide in Screenshots

Hide or shrink when paused

Floating lyrics and the notch disappear while paused or idle; the notch can instead shrink back to the size of the notch.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Hide When Paused
  • Settings: Lyrics Display › Notch › Behavior › Hide When Paused
  • Settings: Lyrics Display › Notch › Behavior › Shrink When Paused

Notch steps aside in full screen

Notch lyrics tuck away while a video, game or any app is full screen.

  • On by default
  • Settings: Lyrics Display › Notch › Behavior › Hide in Full Screen

Title drops in on song change

Each new song's title and artist slide out of the notch for a moment, then tuck back in.

  • On by default
  • Settings: Lyrics Display › Notch › Behavior › Show Title on Song Change

Listening milestones

When a song reaches its 100th, 1,000th or 10,000th play, or your Last.fm total passes a milestone, the notch opens up to celebrate. Needs Last.fm connected.

  • On by default
  • Settings: Lyrics Display › Notch › Behavior › Listening Milestones

5 Players and playback

Nine players, pick several or detect automatically

Apple Music, Spotify, QQ Music, NetEase Cloud Music, Kugou, Soda Music, KKBOX, Amazon Music and the YouTube Music app Kaset. Choose several at once, or leave it on automatic to follow whatever macOS shows as Now Playing. Apple Music radio works too, showing the station name and logo while the host talks.

  • Settings: Player › Player

YouTube Music and Spotify Web in your browser

Pair your browser once and music playing in it gets lyrics too, following the page's own progress. A one-click check tells you first whether that browser can be controlled. During ads the notch shows the time left and which ad it is.

  • Off by default
  • Settings: Player › Web Players

Skip YouTube Music ads automatically

YouTube Music in your browser has its ads skipped the moment the Skip button appears. With it off, you can still skip from the notch yourself. Needs the Accessibility permission.

  • Off by default
  • Settings: Player › Web Players › Skip YouTube Music Ads Automatically
  • Settings: Player › Accessibility

Add other players

Players not on the list can be added to your trusted players from Applications, and Lyrimuse asks when it notices an unfamiliar player making music.

  • Settings: Player › Trusted Players
  • Settings: Player › Trusted Players › Add a Player…
  • Settings: Player › New Player Alerts

Permissions, only where needed

Apple Music, Spotify and Kaset need Automation permission to read what is playing. QQ Music, NetEase Cloud Music and Kugou need Full Disk Access for their saved lyrics and queues. Amazon Music's progress calibration and QQ Music's shuffle, repeat and like buttons need Accessibility. Web players need Automation for the browser and its Allow JavaScript from Apple Events option. The other players need nothing. Settings shows the current state of each.

  • Settings: Player › Automation Permission
  • Settings: Player › Full Disk Access
  • Settings: Player › Accessibility

Playback controls and seeking

Play, pause, skip and drag the progress bar from the lyrics window or the expanded notch. Shuffle, repeat, like and volume depend on the player: Apple Music, Spotify, Kaset, QQ Music, Amazon Music and YouTube Music in a browser each support some or all of them. Play, pause and skipping can have global shortcuts.

  • Settings: Lyrics Display › Notch › Expanded State › Show Playback Controls
  • Settings: Keyboard Shortcuts › Play/Pause
  • Settings: Keyboard Shortcuts › Next Track
  • Settings: Keyboard Shortcuts › Previous Track

Open the song's page in one click

One click in the ⋯ menu opens the song, its album or its artist on the platform you are playing from. Apple Music and KKBOX open in their own apps, and Spotify jumps to the song in its app; the rest open on the web: Spotify albums and artists, QQ Music, Soda Music, Amazon Music and YouTube Music. NetEase Cloud Music has the song page only; Kugou has none.

Song, album and artist notes

Click the title, artist or album in the lyrics window or the expanded notch to read about it. Album and artist notes come from Apple Music first; failing that, from Soda Music and NetEase Cloud Music (Chinese interface only), then Wikipedia via YouTube Music, then Last.fm. Song notes come from QQ Music (Chinese interface only) or Last.fm. Last.fm needs your account connected.

Start and quit together with your player

Per player: open the player when Lyrimuse opens, open Lyrimuse when the player opens, or quit Lyrimuse once every player it follows has quit.

  • Off by default
  • Settings: Player › Player Linkage › Launch When Lyrimuse Opens
  • Settings: Player › Player Linkage › Launch When Your Player Opens
  • Settings: Player › Player Linkage › Quit With Player

6 Scrobbling, Last.fm and sharing

Last.fm scrobbling and listening profile

Connect Last.fm in one click, no token to copy. See today's, this week's and all-time listening, artist, album and track charts with movement, and Footprints: a year heatmap, listening hours, where your artists come from, and On This Day. Love any recent track with a click.

  • Off by default
  • Settings: Last.fm › Settings › Scrobble Rules

Scrobble rules are yours

Count a play at 50%, 75%, 90% or only at the end; decide on tracks under 30 seconds; by default featured artists, Chinese script variants and suffixes like “- Single” are matched to Last.fm's catalogue entry, or send everything as is; leave any player out of Last.fm entirely.

  • Settings: Last.fm › Settings › Scrobble Point
  • Settings: Last.fm › Settings › Tracks Under 30 Seconds
  • Settings: Last.fm › Settings › Matching Mode
  • Settings: Last.fm › Settings › Players to Scrobble

Every play is logged locally first

Plays are recorded on your Mac while Last.fm is not connected, or when one fails to send. Once connected, click Backfill under Pending Scrobbles on the Last.fm page; Last.fm only accepts plays from about the last two weeks.

Scrobble to ListenBrainz too

Each play goes to Last.fm and ListenBrainz from the same reading, so the two agree. Plays your iPhone sends to Last.fm can be copied into ListenBrainz as well. Under Lab Features, which is collapsed in the sidebar by default.

  • Off by default
  • Settings: Lab Features › ListenBrainz › Account Info

Show what you're playing on Discord

Your profile and friends list show the player, title, artist, artwork and a progress bar; clicking the title or artist opens the player's web page. Choose which players count, whether it stays while paused and which badge sits on the artwork, or hide it for a while.

  • Off by default
  • Settings: Discord › Show on Discord
  • Settings: Discord › Players Shown
  • Settings: Discord › When Paused
  • Settings: Discord › Hide Temporarily

A shareable now-playing web page

A public page with what you are playing and your history, with optional guestbook, reactions, visitor count, top 10 artists and a vinyl look. ListenBrainz alone gives live playback and history; deploy a Cloudflare Worker from the guide for the rest. Under Lab Features.

  • Off by default
  • Settings: Lab Features › Web Push › Connection Info

Daily, weekly, monthly and yearly listening digests

Sent to you as push notifications through Bark, DingTalk, WeCom, Discord, Feishu, ServerChan or Telegram. Each of the four has its own switch. Under Lab Features.

  • Off by default
  • Settings: Lab Features › Push Alerts › Alerts
  • Settings: Lab Features › Push Alerts › Daily Listening Report
  • Settings: Lab Features › Push Alerts › Weekly Listening Digest
  • Settings: Lab Features › Push Alerts › Monthly Listening Digest
  • Settings: Lab Features › Push Alerts › Yearly Listening Digest

7 Everyday

First-launch setup

The first time you open Lyrimuse, it walks you through choosing players, pairing a browser and picking where lyrics appear, and checks each permission you need so you can fix anything missing on the spot.

English, Simplified and Traditional Chinese

Follows your system by default; switching takes effect at once, without a restart.

  • Settings: General › Language & Startup › Language

Showing or hiding each kind of lyrics, opening the lyrics window and Lyrics Manager, searching, timing and playback can all have shortcuts. None are assigned by default.

  • Settings: Keyboard Shortcuts › Open Settings

Searchable settings

Type at the top of the settings sidebar to jump straight to a setting, highlighted, even inside collapsed sections. Search in English or Chinese.

Menu bar icon

Twelve icons to choose from, moving with the music while it plays. Everyday actions live in its menu.

  • On by default
  • Settings: General › Menu Bar & Dock › Menu Bar Icon
  • Settings: General › Menu Bar & Dock › Move with the Music

Show in Dock

Turn it off to keep only the menu bar icon.

  • On by default
  • Settings: General › Menu Bar & Dock › Show in Dock

Launch at login

Opens Lyrimuse when you log in to your Mac.

  • On by default
  • Settings: General › Language & Startup › Launch at Login

Launch silently

Starts without opening any window, just the menu bar icon.

  • Off by default
  • Settings: General › Language & Startup › Launch Silently

Notify when the song changes

A system notification for every new song.

  • Off by default
  • Settings: General › Notifications › Notify When the Song Changes

Back up settings, move to a new Mac

Export all your settings to one file, saved to iCloud Drive by default or to a folder you choose; when a new Mac first opens Lyrimuse and finds it in iCloud, it offers to import it.

  • Settings: General › Backup & Migration › iCloud Backup
  • Settings: General › Backup & Migration › Settings File

Automatic updates and betas

Checks for new versions by itself; read the notes and install from the Software Update page. Turn on Beta Updates to try new things early.

  • Off by default
  • Settings: Software Update › Automatic Updates › Check Automatically
  • Settings: Software Update › Automatic Updates › Download and Install Automatically
  • Settings: Software Update › Beta Updates

One-click diagnostics and bug reports

Bundles logs, crash reports and app state into one file with credentials and your user name removed. Report an Issue opens a GitHub issue with your version, macOS and player filled in.

  • Settings: About › Diagnostics & Data › Export Diagnostics
  • Settings: About › Feedback › Report an Issue

8 Every setting

Every setting in the Settings window, by where it lives: 213 in all. Type a name into the search field at the top of the Settings sidebar to jump straight to it.

Lyrics › Sources

  • Lyrics Sources
  • Matching Algorithm
  • Re-Pick After Algorithm Updates: On (default): when the matching algorithm or scoring rules change, existing lyrics are re-evaluated in the background and may be swapped for a better match Off: once chosen, lyrics are never swapped automatically; first-time lookups, manual re-searches and manual edits are unaffected
  • Pre-Resolve Upcoming Tracks
  • Lock Hand-Picked Lyrics: Off (default): swaps in this version now — later auto re-searches or scoring changes can still replace it On: locks this song’s lyrics; automatic matching won’t touch it again Turning it on also locks songs you picked earlier (except those already replaced automatically)

Lyrics › Translation

  • Translation Language: The language you want translations in. Whether Floating Lyrics, the Lyrics Window and the others show them is set for each one in Lyrics Display
  • System Fallback Translation: Fills in where the lyrics source ships none
  • Translation Languages: Counts only languages that can be translated into the current translation language; the target language itself and languages in the same family are excluded, so the number can be lower than in System Settings. Language packs are managed by macOS and translation runs on this Mac

Lyrics › Adjust

  • Chinese Script: Show Chinese lyrics in simplified or traditional throughout
  • Romanization Languages: Which languages get romanization. Whether Floating Lyrics, the Lyrics Window and the others show it is set for each one in Lyrics Display
  • Split Long Lines: On Desktop Floating Lyrics, the Notch, the Menu Bar and the Touch Bar, lines too wide for one row are split into parts shown one after another, so no line wraps or scrolls; the Lyrics Window still shows one line at a time
  • Join Short Lines: On Desktop Floating Lyrics, the Notch, the Menu Bar and the Touch Bar, runs of very short lines are shown as one line, only when the result fits on one row; the Touch Bar is wide, so there adjacent lines are joined whenever they fit and last 5 seconds or less in total; the Lyrics Window still shows one line at a time
  • Timing Offset: Positive shows lyrics earlier, negative later

Lyrics › Library

  • Lyrics Library
  • Auto-Match Missing Lyrics: Auto-matches songs with no lyrics or plain text only. Instrumentals and manually edited songs are left alone.
  • Re-Match Whole Library: Re-matches songs that already have lyrics too, except manually edited, timing-calibrated and instrumental songs
  • Lyrics Folder: Existing files aren't moved to the new folder

Player

  • Player
  • Web Players: Web players don't report precise position; this switch lets Lyrimuse recalibrate right after a track change.
  • Trusted Players
  • New Player Alerts
  • Automation Permission
  • Full Disk Access
  • Accessibility
  • Lyrics Engine: Reads playback state and fetches lyrics and artwork
  • Player Linkage: Each item is checked per player. Only the selected players are listed; with Auto-detect selected, the ones installed on this Mac are added

Player › Web Players

  • Skip YouTube Music Ads Automatically: Presses Skip as soon as it appears; ads that can't be skipped still play. Needs Accessibility permission. If YouTube Music is in a background tab, Lyrimuse briefly switches to it and back without touching the browser window you're using.
