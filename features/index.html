Every feature and setting

Lyrimuse v1.11.0, released October 2026

Lyrimuse is an open-source (GPL-3.0) Mac app for word-by-word synced lyrics, for macOS 14 or later on Apple Silicon and Intel. It shows lyrics for Apple Music, Spotify, QQ Music, NetEase Cloud Music, Kugou, Soda Music, KKBOX, Amazon Music, LX Music, Kaset, reAMP, and YouTube Music or Spotify Web playing in a browser: floating on the desktop, beside the notch, in the menu bar, on the Touch Bar or in a full lyrics window, with translations and romanization (pinyin, Cantonese Jyutping, Japanese romaji, Korean romanization). It scrobbles to Last.fm and ListenBrainz and can show what you play on Discord. The interface is in English, Simplified Chinese and Traditional Chinese.

This page lists every Lyrimuse feature: what it does, where it lives in Settings and whether it is on after you install, followed by every setting in the Settings window. The same list is on GitHub as Markdown.

2 Finding lyrics

Fourteen lyric sources, searched automatically

NetEase Cloud Music, QQ Music, Kugou, Kuwo, Migu, Musixmatch, LRCLIB, LyricFind, Deezer, AMLL, Soda Music, VIBE, Genie and Apple Music. Each source can be turned off, reordered, or tested to see whether it is reachable right now.

  • On by default
  • Settings: Lyrics › Sources › Lyrics Sources

Apple Music's own lyrics

Connect your Apple Music account under Lyrics Sources to use Apple Music's own lyrics, many of them timed word by word. Needs an Apple Music subscription.

  • Off by default
  • Settings: Lyrics › Sources › Lyrics Sources

Smart matching

By default every result is scored on title, artist, length and version (live, instrumental and so on), and the best fit for the song that is playing wins. You can switch to source order instead: no scoring, the first source in your order that has lyrics is used.

  • Settings: Lyrics › Sources › Matching Algorithm

Re-pick lyrics when matching improves

When a new version improves matching or scoring, lyrics you already have are re-checked in the background and replaced if a better version turns up. Turn it off to keep lyrics once they are chosen.

  • On by default
  • Settings: Lyrics › Sources › Re-Pick After Algorithm Updates

Lyrics ready before the next song

Reads your player's queue and finds lyrics for the next few songs ahead of time; when there is no queue to read, it works through the rest of the album. QQ Music, NetEase Cloud Music, Kugou and Soda Music need Full Disk Access for this.

  • On by default
  • Settings: Lyrics › Sources › Pre-Resolve Upcoming Tracks
  • Settings: Player › Permissions & Services › Full Disk Access

Use the lyrics your player already saved

Lyrics that QQ Music, NetEase Cloud Music, Kugou, KKBOX, Amazon Music and LX Music already saved can be used directly: the same version the player shows, and faster. For reAMP, the lyrics inside the playing file or a .lrc file of the same name are used. QQ Music, NetEase Cloud Music and Kugou need Full Disk Access for Lyrimuse in System Settings; without it lyrics are still found online.

  • Off by default
  • Settings: Player › Permissions & Services › Full Disk Access

Warns you when a lyric source misbehaves

When a lyric source has lately found almost nothing, far less than usual, or keeps failing or timing out, a warning appears next to it under Lyrics Sources; click it for the numbers behind it. The other sources keep searching, and the counting happens only on your Mac.

  • Settings: Lyrics › Sources › Lyrics Sources

Lock hand-picked lyrics

When on, lyrics you pick by hand from search results are locked, so later automatic matching and re-matching never replace them.

  • Off by default
  • Settings: Lyrics › Sources › Lock Hand-Picked Lyrics

Lyrics Manager

Browse, edit, delete or search again for any song's lyrics, delete in bulk, and clear out the empty entries ads and podcasts leave behind. Give a single song its own timing offset. Retry every song that has no lyrics yet in one go, or re-match the whole library under the current rules, with an adjustable pause between songs; anything you edited by hand is left alone.

  • Settings: Lyrics › Library › Lyrics Library
  • Settings: Lyrics › Library › Auto-Match Missing Lyrics
  • Settings: Lyrics › Library › Re-Match Whole Library
  • Settings: Keyboard Shortcuts › Open Lyrics Manager
  • Settings: Lyrics › Library › Scan Interval

Entries for the same song

The same song played in different players or from different releases is recognized as one song: its entries share one set of lyrics, hand edits and timing fixes carry over, and play counts are added up. In Lyrics Manager, Entries for This Song compares each entry's lyrics line by line, and an entry matched by mistake can be split off and merged back later. Turn the sharing off to have each entry matched on its own.

  • On by default
  • Settings: Lyrics › Sources › Share Lyrics Across Entries of a Song

Swap or fix lyrics on the spot

From the lyrics window's ⋯ menu, search for other lyrics, run matching again, or edit them in your own text editor. Editing word-timed lyrics changes only the words, never their timing.

  • Settings: Keyboard Shortcuts › Search Lyrics

Works offline; lyrics are plain .lrc files

Every lyric found is cached on your Mac and shows without a connection. Each song has an .lrc file, plus .tr.lrc and .roma.lrc for translations and romanization, and word timing in .yrc. They live in ~/.config/lyrimuse/lyrics/ by default, and the folder can be moved.

  • Settings: Lyrics › Library › Lyrics Folder

3 Translation, romanization and line handling

Translations

Translations that come with the lyrics appear under each line. NetEase Cloud Music, QQ Music and Kugou translate into Chinese; Musixmatch and machine translation follow the translation language you pick, from 17. Floating lyrics, the lyrics window, the notch, the menu bar and the Touch Bar each decide whether to show them. Shown by default when your Mac's languages include Chinese.

  • Settings: Lyrics › Translation › Translation Language
  • Settings: Lyrics Display › Floating Lyrics › Content › Translation
  • Settings: Keyboard Shortcuts › Show/Hide Translation

Translate when none is provided

When no source has a translation, the lyrics are translated by machine. On macOS 15 or later with the language downloaded, Apple Translation does it on your Mac and the lyrics stay there; otherwise the lines to translate are sent to Google Translate, then MyMemory. Translation languages are downloaded from the same card.

  • Off by default
  • Settings: Lyrics › Translation › Translate When None Is Provided
  • Settings: Lyrics › Translation › Translation Languages

Romanization

Japanese romaji, Korean romanization, Mandarin pinyin and Cantonese Jyutping, word by word above the lyrics. Language is judged line by line, so a Japanese line inside a Chinese song is the only one marked. Choose which languages to mark here; with a Chinese interface, pinyin starts off. Each display decides whether to show them.

  • On by default
  • Settings: Lyrics › Adjust › Romanization Languages
  • Settings: Lyrics Display › Floating Lyrics › Content › Romanization
  • Settings: Keyboard Shortcuts › Show/Hide Romanization

Simplified or Traditional Chinese

Shows all Chinese lyrics in Simplified or Traditional characters, whatever language the app itself is in.

  • Settings: Lyrics › Adjust › Chinese Script

Split long lines, join short ones

Floating lyrics, the notch, the menu bar and the Touch Bar split lines too long for their width and join lines that flash by too quickly, each by its own width. The lyrics window keeps one line per line. Two separate switches.

  • Off by default
  • Settings: Lyrics › Adjust › Split Long Lines
  • Settings: Lyrics › Adjust › Join Short Lines

Timing offset

Move all lyrics earlier or later, optionally for one player only. Single songs get their own offset in the Lyrics Manager, and shortcuts can advance, delay or reset it on the fly.

  • Settings: Lyrics › Adjust › Timing Offset
  • Settings: Keyboard Shortcuts › Advance Lyrics
  • Settings: Keyboard Shortcuts › Delay Lyrics
  • Settings: Keyboard Shortcuts › Reset Lyrics Offset

4 Where lyrics appear and how they look

Desktop floating lyrics

Lyrics floating above every window, always on top, lit up word by word. Leave them wherever you drag them, or pin them to the top centre of the screen or just above the Dock. With several displays they can stay on one screen or follow the screen of the window you are using. Romanization, translation and the next line can show alongside.

  • On by default
  • Settings: Lyrics Display › Floating Lyrics › Desktop Floating Lyrics
  • Settings: Lyrics Display › Floating Lyrics › Position
  • Settings: Lyrics Display › Floating Lyrics › Content › Next Line
  • Settings: Keyboard Shortcuts › Show/Hide Floating Lyrics
  • Settings: Lyrics Display › Floating Lyrics › Screen

Notch lyrics

A Dynamic Island-style capsule beside the notch at the top of the screen; Macs without a notch and external displays get one too. Each side can show the title, artist, album, artwork, playback controls, or elapsed or remaining time, next to a moving audio wave. Hover to expand it for controls, a seekable progress bar, lyrics timing and quick buttons such as like and search lyrics. During ads it counts down the time left.

  • Off by default
  • Settings: Lyrics Display › Notch › Notch Lyrics
  • Settings: Lyrics Display › Notch › Style
  • Settings: Lyrics Display › Notch › Display
  • Settings: Lyrics Display › Notch › Left Ear
  • Settings: Keyboard Shortcuts › Show/Hide Notch Lyrics
  • Settings: Lyrics Display › Notch › Expanded State › Quick Actions

Menu bar lyrics

The current line right in the menu bar, scrolling when it is too long instead of being cut off. Add a second line for the next line, the translation or romanization.

  • Off by default
  • Settings: Lyrics Display › Menu Bar › Menu Bar Lyrics
  • Settings: Lyrics Display › Menu Bar › Layout › Second Line
  • Settings: Keyboard Shortcuts › Show/Hide Menu Bar Lyrics

Touch Bar lyrics

On a MacBook Pro with a Touch Bar, the current line scrolls along as it is sung, with optional artwork and playback controls. The lyrics can be white, follow the artwork or use your own color, with adjustable brightness for the unsung part. They can expand when playback starts and fold away when paused, and a More button brings up timing, like, shuffle and repeat, volume and a progress slider.

  • Off by default
  • Settings: Lyrics Display › Touch Bar › Touch Bar Lyrics
  • Settings: Keyboard Shortcuts › Expand/Collapse Touch Bar Lyrics
  • Settings: Lyrics Display › Touch Bar › Style › Lyrics Color
  • Settings: Lyrics Display › Touch Bar › Behavior › Expand When Playback Starts
  • Settings: Lyrics Display › Touch Bar › Layout › Show More Button

Lyrics window

Full-page lyrics modelled on Apple Music's lyrics view: blurred artwork behind, the whole song scrolling to the current line, duets split by singer, background vocals on their own line, held notes that swell and glow. The background can follow the artwork or be solid, a gradient or frosted glass, and the text weight, sung color and alignment can be changed. Open it from the menu bar icon or a shortcut.

  • Settings: Lyrics Display › Lyrics Window › Lyrics Window
  • Settings: Lyrics Display › Lyrics Window › Background › Background
  • Settings: Keyboard Shortcuts › Open Lyrics Window
  • Settings: Lyrics Display › Lyrics Window › Layout › Alignment

Lyrics window HDR highlight

On an HDR display, the sung part of the current line in the lyrics window is brightened past normal white. Off by default and uses more power when on. Full size only.

  • Off by default
  • Settings: Lyrics Display › Lyrics Window › Text › HDR Highlight

Mini lyrics window

The lyrics window shrunk to a small card: just the current line, the current and next line, or a full scrolling page. Background, text colour, font, weight, sung colour and the title, artwork and time at the top are all set separately.

  • Settings: Lyrics Display › Lyrics Window › Layout › Lyrics Layout
  • Settings: Keyboard Shortcuts › Switch Mini / Full Size

Mini window hides when paused or in full screen

The mini window can disappear while paused or idle and come back when playback starts, and step aside while an app is full screen on its display (a video, a game). Each is a separate switch.

  • Off by default
  • Settings: Lyrics Display › Lyrics Window › Behavior › Hide When Paused
  • Settings: Lyrics Display › Lyrics Window › Behavior › Hide in Full Screen

Animated artwork

Albums with animated artwork on Apple Music move in the full-size lyrics window too. It pauses in Low Power Mode or with Reduce Motion on. You can see how much space the downloaded animations take and clear them.

  • On by default
  • Settings: Lyrics Display › Lyrics Window › Artwork › Animated Artwork
  • Settings: Lyrics Display › Lyrics Window › Artwork › Animated Artwork Cache

Listening overview between songs

When nothing is playing, the lyrics window shows the last song with a line from its lyrics and a Resume button. With Last.fm connected it also shows how much you listened today, in the last 7 days and in total, a 30-day trend, On This Day and your recent plays with artwork.

Appearance

Font (the system's, or your own .ttf / .otf), size, weight, text and background colours, outline and frosted glass. Floating lyrics come with colour themes and can save your own; text colour can follow the album artwork. Shortcuts, or scrolling over the lyrics with ⌘ held (mouse wheel or two-finger swipe), can also make floating lyrics bigger or smaller on the fly.

  • Settings: Lyrics Display › Floating Lyrics › Theme › Color Theme
  • Settings: Lyrics Display › Floating Lyrics › Theme › My Themes
  • Settings: Lyrics Display › Floating Lyrics › Type › Font
  • Settings: Lyrics Display › Floating Lyrics › Color › Frosted Glass Background
  • Settings: Keyboard Shortcuts › Increase Floating Lyrics Font Size
  • Settings: Keyboard Shortcuts › Decrease Floating Lyrics Font Size

Word-by-word karaoke fill

Each word lights up as it is sung. Floating lyrics, the notch, the menu bar, the Touch Bar and both sizes of the lyrics window each have their own switch; off means the whole line lights at once.

  • On by default
  • Settings: Lyrics Display › Floating Lyrics › Color › Karaoke Effect
  • Settings: Lyrics Display › Notch › Lyric Row › Karaoke Effect
  • Settings: Lyrics Display › Menu Bar › Color › Karaoke Effect
  • Settings: Lyrics Display › Touch Bar › Style › Karaoke Effect
  • Settings: Lyrics Display › Lyrics Window › Text › Karaoke Effect

Line transition

When floating lyrics move to the next line, the old line slides up and the new one follows, instead of swapping in place.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Layout › Line Transition

Fade when the pointer is over it

Floating lyrics turn see-through while the pointer is over them, so they never block what is underneath. The mini lyrics window has its own switch, and can also let clicks through to the window underneath while faded; hold ⌥ to use the mini window.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Fade on Hover
  • Settings: Lyrics Display › Lyrics Window › Behavior › Fade on Hover
  • Settings: Lyrics Display › Lyrics Window › Behavior › Click Through While Faded

Lock position, long-press to drag

Lock floating lyrics in place, or require a long press before dragging so they never move by accident.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Lock Position
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Long-Press to Drag
  • Settings: Keyboard Shortcuts › Lock/Unlock Position

Controls on hover

Pointing at floating lyrics brings up a row of quick buttons. Menu bar lyrics can show playback controls on hover too.

  • On by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Controls on Hover
  • Settings: Lyrics Display › Menu Bar › Behavior › Show Controls on Hover

Hidden from screenshots and screen sharing

Screenshots, recordings and shared screens leave the lyrics out while you still see them. Floating lyrics and the notch each have a switch.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Hide in Screenshots
  • Settings: Lyrics Display › Notch › Behavior › Hide in Screenshots

Hide or shrink when paused

Floating lyrics and the notch disappear while paused or idle; the notch can instead shrink back to the size of the notch.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Hide When Paused
  • Settings: Lyrics Display › Notch › Behavior › Hide When Paused
  • Settings: Lyrics Display › Notch › Behavior › Shrink When Paused

Hide for instrumentals and songs without lyrics

When a song is instrumental, or the search is done and found no lyrics, floating lyrics can hide, and the notch and the Touch Bar can fold their lyric row away. Nothing hides while the search is still running. Each has its own switch.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Hide for Instrumentals & No Lyrics
  • Settings: Lyrics Display › Notch › Behavior › Collapse Lyric Row for Instrumentals & No Lyrics
  • Settings: Lyrics Display › Touch Bar › Behavior › Collapse for Instrumentals & No Lyrics

Notch steps aside in full screen

Notch lyrics tuck away while a video, game or any app is full screen.

  • On by default
  • Settings: Lyrics Display › Notch › Behavior › Hide in Full Screen

Floating lyrics step aside in full screen

Floating lyrics normally stay on top of full screen apps. Turn this on and they hide while a video, game or any app is full screen, then come back when you leave it.

  • Off by default
  • Settings: Lyrics Display › Floating Lyrics › Behavior › Hide in Full Screen

Title drops in on song change

Each new song's title and artist slide out of the notch for a moment, then tuck back in.

  • On by default
  • Settings: Lyrics Display › Notch › Behavior › Show Title on Song Change

Listening milestones

When a song reaches its 100th, 1,000th or 10,000th play, or your Last.fm total passes a milestone, the notch opens up to celebrate. Needs Last.fm connected.

  • On by default
  • Settings: Lyrics Display › Notch › Behavior › Listening Milestones

Web lyrics: a phone or tablet as a second screen, or an OBS browser source

Lyrics in a web browser. Web Lyrics shows exactly what the lyrics window shows; OBS Output has a transparent background and the same fonts and colors as the floating lyrics. Each has its own port and local network setting. Both are available only on this Mac until you turn on "Allow Local Network Access"; then devices on the same network can scan a QR code to connect, using a link with an access key. With "Allow Remote Control" on, the page can also control playback and jump to a line.

  • Off by default
  • Settings: Lyrics Display › Lyrics Window › Web Lyrics
  • Settings: Lyrics Display › Lyrics Window › Web Lyrics › Allow Local Network Access
  • Settings: Lyrics Display › Floating Lyrics › OBS › OBS Output
  • Settings: Lyrics Display › Lyrics Window › Web Lyrics › Allow Remote Control

5 Players and playback

Eleven players, pick several or detect automatically

Apple Music, Spotify, QQ Music, NetEase Cloud Music, Kugou, Soda Music, LX Music, KKBOX, Amazon Music, the Winamp-style reAMP and the YouTube Music app Kaset. Choose several at once, or leave it on automatic to follow whatever macOS shows as Now Playing. Apple Music radio works too, showing the station name and logo while the host talks.

  • Settings: Player › Music Apps

YouTube Music and Spotify Web in your browser

Pair your browser once and music playing in it gets lyrics too, following the page's own progress. A one-click check tells you first whether that browser can be controlled. During ads the notch shows the time left and which ad it is.

  • Off by default
  • Settings: Player › Web

Skip YouTube Music ads automatically

YouTube Music in your browser has its ads skipped the moment the Skip button appears. With it off, you can still skip from the notch yourself. Needs the Accessibility permission.

  • Off by default
  • Settings: Player › Web › Skip YouTube Music Ads Automatically
  • Settings: Player › Permissions & Services › Accessibility

Add other players

Players not on the list can be added to your trusted players from Applications, and Lyrimuse asks when it notices an unfamiliar player making music.

  • Settings: Player › Other Apps
  • Settings: Player › Add App…
  • Settings: Player › New Player Alerts

Permissions, only where needed

Apple Music, Spotify and Kaset need Automation permission to read what is playing. QQ Music, NetEase Cloud Music and Kugou need Full Disk Access for their saved lyrics and queues, and Soda Music for its queue. Amazon Music's progress calibration, the shuffle, repeat and like buttons of QQ Music, NetEase Cloud Music, Kugou Music, Soda Music, Amazon Music and reAMP, and the playback buttons of QQ Music, NetEase Cloud Music and Soda Music while another app holds Now Playing need Accessibility. Web players need Automation for the browser and its Allow JavaScript from Apple Events option. The other players need nothing. Settings shows the current state of each.

  • Settings: Player › Permissions & Services › Automation Permission
  • Settings: Player › Permissions & Services › Full Disk Access
  • Settings: Player › Permissions & Services › Accessibility

Playback controls and seeking

Play, pause, skip and drag the progress bar from the lyrics window or the expanded notch. Shuffle, repeat, like and volume depend on the player: Apple Music, Spotify, Kaset, QQ Music, Amazon Music and YouTube Music in a browser each support some or all of them, and NetEase Cloud Music, Kugou Music, Soda Music and LX Music have like, with LX Music volume too once Open API is on in its settings. Play, pause, skipping and like can have global shortcuts. While something like a browser video holds Now Playing, play, pause and skipping for QQ Music, NetEase Cloud Music and Soda Music go through their own menus or play bar, and seeking isn't available.

  • Settings: Lyrics Display › Notch › Expanded State › Show Playback Controls
  • Settings: Keyboard Shortcuts › Play/Pause
  • Settings: Keyboard Shortcuts › Next Track
  • Settings: Keyboard Shortcuts › Previous Track
  • Settings: Keyboard Shortcuts › Favorite/Remove Favorite
  • Settings: Player › Permissions & Services › LX Music Open API

Open the song's page in one click

One click in the ⋯ menu opens the song, its album or its artist on the platform you are playing from. Apple Music and KKBOX open in their own apps, and Spotify jumps to the song in its app; the rest open on the web: Spotify albums and artists, QQ Music, Soda Music, Amazon Music and YouTube Music. NetEase Cloud Music has the song page only; Kugou has none.

Song, album and artist notes

Click the title, artist or album in the lyrics window or the expanded notch to read about it. Album and artist notes come from Apple Music first; failing that, from Soda Music and NetEase Cloud Music (Chinese interface only), then Wikipedia via YouTube Music, then Last.fm. Song notes come from QQ Music (Chinese interface only) or Last.fm. Last.fm needs your account connected.

Start and quit together with your player

Per player: open the player when Lyrimuse opens, open Lyrimuse when the player opens, or quit Lyrimuse once every player it follows has quit.

  • Off by default
  • Settings: Player › Linkage › Launch When Lyrimuse Opens
  • Settings: Player › Linkage › Launch When Your Player Opens
  • Settings: Player › Linkage › Quit With Player

6 Scrobbling, Last.fm and sharing

Last.fm scrobbling and listening profile

Connect Last.fm in one click, no token to copy. See today's, this week's and all-time listening, artist, album and track charts with movement, and Footprints: a year heatmap where clicking a day lists its most played songs, listening hours, where your artists come from, and On This Day. Love any recent track with a click.

  • Off by default
  • Settings: Last.fm › Settings › Scrobble Rules

Custom scrobble rules

Count a play at 50%, 75%, 90% or only at the end; decide on tracks under 30 seconds; by default featured artists, Chinese script variants and suffixes like “- Single” are matched to Last.fm's catalogue entry, or send everything as is; leave any player out of Last.fm entirely.

  • Settings: Last.fm › Settings › Scrobble Point
  • Settings: Last.fm › Settings › Tracks Under 30 Seconds
  • Settings: Last.fm › Settings › Matching Mode
  • Settings: Last.fm › Settings › Players to Scrobble

Every play is logged locally first

Plays made while Last.fm is not connected are recorded on your Mac; once connected, click Backfill under Pending Scrobbles on the Last.fm page. A play that may not have reached Last.fm while connected is checked against Last.fm and resent automatically. Last.fm only accepts plays from about the last two weeks.

Scrobble to ListenBrainz too

Each play goes to Last.fm and ListenBrainz from the same reading, so the two agree. Plays your iPhone sends to Last.fm can be copied into ListenBrainz as well. Under Labs in the sidebar.

  • Off by default
  • Settings: Labs › ListenBrainz › Account Info

Show what you're playing on Discord

Your profile and friends list show the player, title, artist, artwork and a progress bar; clicking the title or artist opens the player's web page. The album line can show the line being sung, and up to two buttons can be added. Choose how the text is laid out, which players count, whether it stays while paused and which badge sits on the artwork, show only the player without naming the song, or hide it for a while.

  • Off by default
  • Settings: Discord › Show on Discord
  • Settings: Discord › Players Shown
  • Settings: Discord › When Paused
  • Settings: Discord › Hide Temporarily
  • Settings: Discord › What's Shown
  • Settings: Discord › Buttons
  • Settings: Discord › Hide Song Details

A shareable now-playing web page

A public page with what you are playing and your history, with optional guestbook, reactions, visitor count, top 10 artists and a vinyl look. ListenBrainz alone gives live playback and history; deploy a Cloudflare Worker from the guide for the rest. Under Labs.

  • Off by default
  • Settings: Labs › Web Push › Connection Info

8 Every setting

Every setting in the Settings window, by where it lives: 270 in all. Type a name into the search field at the top of the Settings sidebar to jump straight to it.

Lyrics › Sources

  • Lyrics Sources
  • Matching Algorithm
  • Re-Pick After Algorithm Updates: On (default): when the matching algorithm or scoring rules change, existing lyrics are re-evaluated in the background and may be swapped for a better match Off: once chosen, lyrics are never swapped automatically; first-time lookups, manual re-searches and manual edits are unaffected
  • Share Lyrics Across Entries of a Song: On (default): entries of the same song from different players or album editions that are confirmed to be the same recording use the same lyrics, and manual edits apply to all of them Off: each entry is matched on its own, and entries that were synced go back to their original lyrics
  • Pre-Resolve Upcoming Tracks
  • Lock Hand-Picked Lyrics: Off (default): replaces the lyrics this time only; later automatic searches or scoring changes may replace them again On: locks this song’s lyrics so automatic matching no longer changes them Turning it on also locks songs you chose manually before (except those already replaced automatically)

Lyrics › Translation

  • Translation Language: Whether each place shows translations is set in Lyrics Display
  • Translate When None Is Provided: Translates on this Mac first, and online when that isn’t possible
  • Translation Languages: Only languages that can be translated into your translation language are listed, so there may be fewer than in System Settings. Click a language that isn’t downloaded to download it

Lyrics › Adjust

  • Chinese Script: Show Chinese lyrics in Simplified or Traditional characters
  • Romanization Languages: Adds pronunciation for the selected languages; whether it shows is set in Lyrics Display
  • Split Long Lines: Lines too long to fit are split and shown in parts
  • Join Short Lines: Adjacent short lines are merged when they fit on one line
  • Timing Offset: Positive shows lyrics earlier, negative later

Lyrics › Library

  • Lyrics Library
  • Auto-Match Missing Lyrics: Only songs without lyrics or with plain-text lyrics only
  • Re-Match Whole Library: Songs that already have lyrics are re-matched too; manually edited, calibrated and instrumental songs are left unchanged
  • Scan Interval: Seconds between songs; at least 2 seconds is recommended to avoid rate limits
  • Lyrics Folder: Existing files stay where they are when you change the location
