支援的播放器

九款播放器，一套歌詞。

不管用哪個播放器聽歌，歌詞都在同一個地方：桌面、瀏海或選單列。可以同時勾選好幾個，也可以交給自動識別，哪個在播就跟哪個。

  • Apple Music電台也有歌詞，還能用 Apple 自己的歌詞
  • Spotify認準你在聽的版本，網頁版也能用
  • YouTube Music瀏覽器裡聽也有桌面歌詞，廣告還能略過
  • Amazon Music它存下的歌詞也用上，切歌不用等
  • KKBOX「一起聽」時歌詞也跟著走
  • QQ 音樂認準 QQ 裡的那一首，切歌就有歌詞
  • 網易雲音樂網易雲的翻譯直接顯示，隨機播放也馬上有詞
  • 酷狗音樂酷狗存過的歌詞直接拿來用
  • 汽水音樂汽水自己的官方歌詞，推薦串流裡切歌也有詞

常見問題

能同時用好幾個播放器嗎？

能。在設定裡多選，或者勾選「自動識別」：哪個播放器在播歌，就跟哪個。

清單裡沒有的播放器能用嗎？

大多可以。只要它把正在播的歌回報給 macOS，在設定裡把它加進來就行。想要正式支援，可以在 GitHub 提 issue。
