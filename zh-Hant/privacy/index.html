隱私政策

最後更新：2026 年 10 月 4 日

一句話版：Lyrimuse 沒有帳號系統、沒有遙測、沒有統計，開發者也沒有接收 App 資料的伺服器。找歌詞得拿正在播的這首歌去問各個歌詞來源，所以 App 會連線到第三方服務。本頁把它們全部列出來。

1適用範圍

本政策適用於 Lyrimuse macOS App、隨 App 一起安裝的歌詞引擎，以及 yudaotor.github.io/lyrimuse 這個網站。Lyrimuse 是由個人開發者（Yudaotor）維護的開源專案，背後沒有公司。

2我們收集什麼：什麼都不收

沒有註冊、沒有使用者 ID、沒有當機回報、沒有使用統計。開發者沒有經營任何接收 App 資料的伺服器，所以手上沒有任何關於你的資料，也就沒有什麼可以讓你匯出、更正或刪除。

原始碼是公開的，這件事你可以自己查證，不必只聽我說。

3留在你 Mac 上的東西

App 記住的一切都寫在你自己的 Mac 上，主要在 ~/.config/lyrimuse 底下：

  • 你的設定
  • 歌詞快取，所以聽過一次的歌離線也能顯示
  • 本機聆聽歷史，排行榜和「那年今日」就是從它算出來的
  • 你自己連線的服務的憑證，例如 Last.fm 的 session key 或 ListenBrainz 的權杖
  • 下文說的對外請求記錄檔

這些都不會上傳。刪掉那個檔案夾就沒了；隨附的 uninstall.sh --purge 會連同其他檔案一起刪除。

4App 會連線到哪些伺服器

除了表中寫明的帳號憑證，這些請求都不附帶任何能辨識你或你這台 Mac 的資訊。對方能看到的是請求本身，以及你的 IP 位址，這跟你開啟一個網站是一樣的。

5對外請求記錄檔

App 發出的每一次網路請求都會寫進你 Mac 上的一份記錄檔。它只記服務名稱、操作、網域、HTTP 狀態碼和耗時，從不記完整網址、參數、請求內容或任何憑證。

你可以在「主控台」裡查看這份記錄檔，也可以在設定裡匯出診斷資訊時附上它。匯出一定是你手動操作的，檔案存在哪裡由你決定。

6App 要求的權限

  • 「自動化」：選了 Apple Music 或 Spotify 時，用來讀取正在播放的曲目和進度、送出播放控制。在瀏覽器裡聽歌並開啟「網頁播放器進度」時，也會要求對該瀏覽器的「自動化」，用來讀取網頁上播放器的實際進度。
  • 「完整磁碟取用權限」，可選：QQ 音樂、網易雲音樂、酷狗把播放佇列放在受系統保護的檔案夾裡。授權後，Lyrimuse 能提前替接下來要播的歌找好歌詞；不授權只是少了這一步。

其他播放器讀取的是系統的「正在播放」資訊，不需要權限。這些權限只用來跟隨你正在播的歌，沒有其他用途。

7這個網站

這些頁面是放在 GitHub Pages 上的靜態檔案，沒有 cookie、沒有統計指令碼、沒有任何追蹤。頁面只會在你自己瀏覽器的本機儲存空間裡記下你選的語言。開啟下載選單時，頁面會向 GitHub API 查一次最新版本號碼。GitHub 作為代管方會像任何網頁伺服器一樣記錄請求，詳見 GitHub 的隱私權聲明。

8未成年人

Lyrimuse 不以兒童為對象，也不收集任何年齡層任何人的個人資料。

9變更

App 的資料處理方式有變化時，本頁會跟著修改，頂部日期也會更新。本頁的修改歷史在儲存庫裡是公開的。
