# Lyrimuse 기능 목록

[English](feature-list.md) · [简体中文](feature-list.zh-CN.md) · [繁體中文](feature-list.zh-Hant.md) · [日本語](feature-list.ja.md) · 한국어 · [Español](feature-list.es.md) · [Français](feature-list.fr.md) · [Deutsch](feature-list.de.md) · [Italiano](feature-list.it.md) · [Português (Brasil)](feature-list.pt-BR.md) · [Tiếng Việt](feature-list.vi.md) · [Русский](feature-list.ru.md) · [Українська](feature-list.uk.md) · [ไทย](feature-list.th.md)

Lyrimuse는 macOS 14 이상을 지원하고 Apple Silicon과 Intel 칩 모두와 호환되는 오픈 소스(GPL-3.0) macOS 단어별 가사 앱입니다. Apple Music, Spotify, QQ Music, NetEase Cloud Music, Kugou, Soda Music, KKBOX, Amazon Music, LX Music, Kaset, Pear Desktop, reAMP, VOX, Pine Player, foobar2000, Swinsian, Plexamp, 그리고 브라우저에서 재생하는 YouTube Music과 Spotify 웹 플레이어의 가사를 단어 단위로 동기화해 표시합니다. 데스크탑 플로팅 가사, 노치, 메뉴 막대, Touch Bar, 가사 윈도우에 표시할 수 있고, 번역과 로마자 표기(병음, 광둥어 Jyutping, 일본어 로마자, 한국어 로마자)를 제공하며, 재생 기록을 Last.fm과 ListenBrainz에 스크로블하고 Discord에 지금 듣고 있는 노래를 표시할 수도 있습니다. 인터페이스는 중국어 간체, 중국어 번체, 영어, 일본어, 한국어, 스페인어, 프랑스어, 독일어, 이탈리아어, 브라질 포르투갈어, 베트남어, 러시아어, 우크라이나어, 태국어를 지원합니다.

Lyrimuse의 모든 기능을 무엇을 하는지, 설정의 어디에 있는지, 설치 직후 켜져 있는지 꺼져 있는지와 함께 정리했습니다. 마지막에는 설정 윈도우의 모든 항목을 실었습니다. 이 목록은 코드와 함께 관리되며 기능이 바뀔 때마다 갱신됩니다.

## 가사 찾기

<a id="feature-lyric-sources"></a>

### 15개 가사 소스 자동 검색

NetEase Cloud Music, QQ Music, Kugou, Kuwo, Migu, Musixmatch, LRCLIB, LyricFind, Deezer, AMLL, Soda Music, VIBE, Genie, PetitLyrics, Apple Music. 각 가사 소스는 따로 켜거나 끄고, 순서를 바꾸고, 지금 연결할 수 있는지 테스트할 수 있습니다.

- 기본으로 켜짐
- 설정 위치: 가사 › 출처 › 가사 소스

<a id="feature-network-proxy"></a>

### 해외 가사 소스 연결 실패 시 프록시로 재시도

해외 가사 소스에 직접 연결하지 못하면 시스템 프록시나 이 Mac의 Clash 같은 프록시를 통해 자동으로 재시도합니다. 프록시 서버를 직접 지정하거나 프록시를 사용하지 않도록 할 수도 있습니다. 중국 내 가사 소스는 항상 직접 연결합니다.

- 기본으로 켜짐
- 설정 위치: 일반 › 네트워크 › 프록시

<a id="feature-apple-music-lyrics"></a>

### Apple Music 공식 가사

‘가사 소스’에서 Apple Music 계정을 연결하면 Apple Music 공식 가사를 사용할 수 있으며, 대부분의 노래에 단어별 타이밍이 있습니다. Apple Music 구독이 필요합니다.

- 기본으로 꺼짐
- 설정 위치: 가사 › 출처 › 가사 소스

<a id="feature-matching"></a>

### 스마트 매칭

기본적으로 각 가사 소스의 결과에 점수를 매겨 제목, 아티스트, 길이, 버전(라이브, 반주 등)을 기준으로 지금 재생 중인 노래와 가장 잘 맞는 가사를 고릅니다. ‘우선순위 순서’로 바꿀 수도 있으며, 이때는 점수를 매기지 않고 설정한 순서에서 결과가 있는 첫 번째 가사 소스를 사용합니다.

- 설정 위치: 가사 › 출처 › 매칭 알고리즘

<a id="feature-auto-upgrade"></a>

### 매칭 규칙 업데이트 후 다시 선택

새 버전에서 매칭 알고리즘이나 점수 규칙이 개선되면 기존 가사를 백그라운드에서 다시 평가하고, 더 적합한 버전이 있으면 자동으로 교체합니다. 끄면 한 번 선택된 가사는 더 이상 자동으로 바뀌지 않습니다.

- 기본으로 켜짐
- 설정 위치: 가사 › 출처 › 알고리즘 업데이트 후 다시 선택

<a id="feature-prefetch"></a>

### 다음 노래의 가사 미리 가져오기

플레이어의 재생 대기열을 읽어 다음 몇 곡의 가사를 미리 가져옵니다. 대기열을 읽을 수 없으면 같은 앨범의 다른 노래를 먼저 가져옵니다. QQ Music, NetEase Cloud Music, Kugou, Soda Music, VOX의 대기열을 읽으려면 ‘전체 디스크 접근 권한’이 필요합니다.

- 기본으로 켜짐
- 설정 위치: 가사 › 출처 › 재생 예정 곡 미리 분석
- 설정 위치: 플레이어 › 권한 및 서비스 › 전체 디스크 접근 권한

<a id="feature-player-local-lyrics"></a>

### 플레이어가 이 Mac에 저장한 가사 바로 사용

Apple Music, Spotify, Kugou, KKBOX, Amazon Music, LX Music이 이 Mac에 저장한 가사를 바로 사용할 수 있으며, 플레이어에 표시되는 버전과 같고 더 빠릅니다(Apple Music과 Spotify는 플레이어에서 가사를 표시한 적이 있는 노래만 해당). QQ Music과 NetEase Cloud Music은 이 Mac의 보관함으로 재생 중인 노래를 알아내 검색 없이 같은 버전의 가사를 바로 가져옵니다. reAMP, VOX, Pine Player, foobar2000, Swinsian에서 재생할 때, 그리고 Apple Music이 보관함의 로컬 파일을, LX Music이 로컬 목록의 노래를 재생할 때는 파일에 포함된 가사나 같은 이름의 .lrc 파일을 사용합니다. QQ Music, NetEase Cloud Music, Kugou는 시스템 설정에서 Lyrimuse에 ‘전체 디스크 접근 권한’을 허용해야 하며, 허용하지 않아도 온라인에서 가사를 찾을 수 있습니다.

- 기본으로 꺼짐
- 설정 위치: 플레이어 › 권한 및 서비스 › 전체 디스크 접근 권한

<a id="feature-prefer-local-file-lyrics"></a>

### 노래 파일의 가사 우선 사용

이 Mac의 음악 파일을 재생할 때는 같은 이름의 .lrc나 파일에 포함된 가사를 먼저 사용하며, 온라인에서 찾은 가사와 비교하지 않습니다. 플레이어와 관계없이 로컬 파일을 재생 중이면 적용됩니다. 가사가 이 버전과 맞지 않으면(예: 길이가 다르면) 평소처럼 온라인에서 찾습니다.

- 기본으로 꺼짐
- 설정 위치: 가사 › 출처 › 노래 파일의 가사 우선 사용

<a id="feature-lock-hand-picked"></a>

### 직접 선택한 가사 고정

켜면 검색 결과에서 직접 선택한 가사가 고정되어, 이후 자동 매칭이나 다시 매칭으로 교체되지 않습니다.

- 기본으로 꺼짐
- 설정 위치: 가사 › 출처 › 직접 선택한 가사 고정

<a id="feature-lyrics-manager"></a>

### 가사 관리자

모든 노래의 가사를 둘러보고, 편집하고, 삭제하거나 다시 검색할 수 있으며, 여러 개를 선택해 한꺼번에 삭제하고 광고와 팟캐스트가 남긴 빈 항목도 한 번에 정리할 수 있습니다. 타이밍이 맞지 않는 노래는 오프셋을 따로 조정할 수 있습니다. 아직 가사가 없는 노래는 한 번에 모두 다시 시도할 수 있고, 전체 가사 보관함을 현재 규칙으로 다시 매칭할 수도 있으며(노래 사이 간격 조절 가능), 직접 수정한 가사는 영향을 받지 않습니다.

- 설정 위치: 가사 › 가사 보관함 › 가사 보관함
- 설정 위치: 가사 › 가사 보관함 › 누락된 가사 자동 매칭
- 설정 위치: 가사 › 가사 보관함 › 전체 가사 보관함 다시 일치
- 설정 위치: 키보드 단축키 › 가사 관리자 열기
- 설정 위치: 가사 › 가사 보관함 › 스캔 간격

<a id="feature-song-entries"></a>

### 같은 노래의 항목: 같은 노래는 가사 공유

- 설정 위치: 푸시 알림 › 전송 시간

### 딥 링크(lyrimuse://)

lyrimuse:// 링크로 설정의 모든 페이지, 가사 윈도우, 가사 관리자를 열 수 있고, 키보드 단축키로 할 수 있는 모든 작업(재생 제어, 즐겨찾기, 모든 가사 가리기 등)을 실행할 수 있어 단축어, Raycast, Alfred 같은 도구에서 사용할 수 있습니다. 단축어에서 x-callback-url로 열면 노래 제목, 아티스트, 앨범, 현재 가사를 매개변수로 돌려받을 수도 있습니다. ‘키보드 단축키’ 페이지의 ‘딥 링크’ 카드에 모든 링크가 나열되어 있어 바로 복사할 수 있습니다.

- 설정 위치: 키보드 단축키 › 딥 링크

### 메뉴 막대 패널

메뉴 막대 아이콘을 클릭하면 macOS 제어 센터를 본뜬 패널이 열립니다. 아트워크, 가사, 진행 상황, 재생 제어가 있는 재생 중 카드와 각 가사 표시와 윈도우를 켜고 끄는 타일이 있으며, 타일을 길게 누르거나 오른쪽 클릭하면 뒤집혀 자주 쓰는 설정을 바꿀 수 있습니다. 타일은 원하는 대로 배치할 수 있어, 드래그로 옮기고 오른쪽 아래 모서리를 드래그해 크기를 바꾸며, 타일과 하단 버튼을 추가하거나 뺄 수 있습니다. 패널에서 스페이스 바와 화살표 키로 재생을 제어하고 가사 타이밍을 조절할 수 있고, 패널을 여는 단축키도 지정할 수 있습니다.

- 기본으로 켜짐
- 설정 위치: 키보드 단축키 › 메뉴 막대 패널 열기/닫기

### 가사 › 출처

- **가사 소스**
- **매칭 알고리즘**
- **노래 파일의 가사 우선 사용**: 로컬 파일을 재생할 때 같은 이름의 .lrc 또는 파일에 포함된 가사를 먼저 사용합니다
- **알고리즘 업데이트 후 다시 선택**: 백그라운드에서 다시 평가하며, 더 적합한 버전으로 바꿀 수 있습니다
- **같은 노래의 항목 간 가사 공유**: 같은 녹음은 플레이어와 앨범 버전이 달라도 하나를 공유하며, 직접 수정한 내용도 함께 동기화됩니다
- **직접 선택한 가사 고정**: 직접 선택한 가사는 자동 매칭으로 교체되지 않습니다
- **재생 예정 곡 미리 분석**: 다음에 재생할 노래의 가사를 미리 가져옵니다

### 가사 › 언어

- **번역 언어**
- **번역이 없을 때 자동 번역**: 먼저 이 Mac에서 번역하고, 불가능하면 온라인으로 번역합니다
- **번역 언어**: 기기 내 번역에 사용하는 시스템 언어
- **중국어 번체/간체 변환**
- **로마자 표기 언어**
- **일본어 로마자 표기 방식**: 로마자로 표기하거나 한자에만 히라가나를 표기합니다

### 가사 › 타이밍 및 줄 나눔

- **긴 줄 나누기**: 한 줄에 다 표시되지 않으면 여러 부분으로 나누어 차례로 표시합니다
- **짧은 줄 합치기**: 인접한 짧은 줄이 한 줄에 들어가면 합쳐서 표시합니다
- **타이밍 오프셋**: 양수 값은 가사를 더 일찍, 음수 값은 더 늦게 표시합니다

### 가사 › 가사 보관함

- **가사 보관함**
- **누락된 가사 자동 매칭**: 가사가 없거나 일반 텍스트 가사만 있는 노래만 검색합니다
- **전체 가사 보관함 다시 일치**: 이미 가사가 있는 노래도 포함하며, 직접 수정했거나 보정했거나 연주곡인 노래는 제외합니다
- **스캔 간격**: 노래 사이의 간격(초)입니다. 요청 제한을 피하려면 2초 이상을 권장합니다
- **가사 폴더**: 위치를 변경해도 기존 파일은 이동되지 않습니다
- **단어별 가사 포맷**
- **가사 폴더 가져오기**: 폴더의 가사 파일을 보관함의 곡에 대응시킵니다. 가져오기 전에 미리 볼 수 있습니다
- **폴더 가져오기 방식**
- **감시 폴더**: 폴더에 추가되거나 변경된 가사 파일은 자동으로 가져옵니다. 가사가 없는 곡에는 바로 채우고, 가사가 있는 곡은 그대로 둡니다
- **가져오기 보관함**: 가져온 가사 보기 및 삭제

### Discord

- **Discord에 표시**: 켜면 Discord 프로필과 친구 목록에 재생 중인 노래가 표시됩니다. 친구에게 보이지 않으면 Discord의 ‘사용자 설정 › 활동 개인정보’에서 활동 상태 공유를 켜십시오
- **표시 내용**
- **‘듣는 중’ 앞에 표시**: 프로필의 ‘×× 듣는 중’에 들어가는 ××입니다. iOS 및 웹 버전 Discord는 이 설정을 지원하지 않아 플레이어 이름이 계속 표시됩니다 제목 또는 아티스트를 선택하면 사용자 이름 아래에 ‘플레이어’를 선택할 수 없습니다
- **이름 아래에 표시**: Discord는 첫째 줄, 둘째 줄 또는 ‘듣는 중’ 앞의 내용만 사용자 이름 아래에 표시할 수 있습니다. 제목과 아티스트가 모두 이 위치에 없으면 해당 옵션을 사용할 수 없습니다
- **아트워크 배지**
- **일시 정지 후**
- **노래 정보**
- **상태 텍스트**
- **아트워크 및 진행 상황**
- **아티스트와 앨범에 접두어 추가**: 아티스트 앞에 ‘아티스트:’, 앨범 앞에 ‘앨범:’을 붙입니다. 제목과 아티스트가 같은 줄에 있으면 붙이지 않습니다
- **버튼**
- **사용자 지정 버튼**
- **‘플레이어에서 듣기’**: 현재 플레이어 웹사이트에서 이 노래의 페이지를 엽니다. 노래 제목을 클릭하는 것과 같으며, 해당 페이지가 없으면 표시되지 않습니다
- **‘Lyrimuse 받기’**
- **개인정보 보호**
- **잠시 가리기**
- **노래 정보 숨기기**: 사용 중인 플레이어와 재생 진행만 표시하며, 제목, 아티스트, 앨범, 가사, 링크 및 ‘플레이어에서 듣기’ 버튼은 전송하지 않습니다
- **진행 막대 표시**: 끄면 진행 막대가 표시되지 않고 Discord에서 경과 시간이 대신 표시되며, 이 타이머는 끌 수 없습니다
- **표시할 플레이어**
