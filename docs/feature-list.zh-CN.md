# Lyrimuse 功能清单

[English](feature-list.md) · 简体中文 · [繁體中文](feature-list.zh-Hant.md)

Lyrimuse 是一款开源（GPL-3.0）的 macOS 逐字歌词 App，支持 macOS 14 及以上版本，兼容 Apple Silicon 和 Intel 芯片。它为 Apple Music、Spotify、QQ 音乐、网易云音乐、酷狗音乐、汽水音乐、KKBOX、Amazon Music、洛雪音乐、Kaset、reAMP、VOX、Pine Player，以及浏览器中的 YouTube Music 和 Spotify 网页版显示逐字同步的歌词：可显示在桌面悬浮歌词、灵动岛、菜单栏、触控栏和歌词窗口中，并提供译文和读音标注（拼音、粤拼、日语罗马音、韩语罗马字），还可将收听记录打卡到 Last.fm 和 ListenBrainz，并在 Discord 上显示正在收听的歌曲。界面支持简体中文、繁体中文和英文。

这份清单列出 Lyrimuse 的每一项功能：做什么、在设置的哪里、装好后默认开着还是关着；最后附上设置窗口里的全部设置项。清单跟代码一起维护，功能有增减时同步更新。

## 歌词查找

<a id="feature-lyric-sources"></a>

### 十五个歌词源自动查找

网易云音乐、QQ 音乐、酷狗、酷我、咪咕、Musixmatch、LRCLIB、LyricFind、Deezer、AMLL、汽水音乐、VIBE、Genie、PetitLyrics 和 Apple Music。每个歌词源均可单独开关、调整顺序，或测试当前是否可连接。

- 默认开启
- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-network-proxy"></a>

### 海外歌词源连不上时经代理重试

海外歌词源直连失败时，自动经系统代理或本机的 Clash 等代理重试；也可以手动指定代理服务器，或不使用代理。国内歌词源始终直连。

- 默认开启
- 设置位置：通用 › 网络 › 代理

<a id="feature-apple-music-lyrics"></a>

### Apple Music 官方歌词

在「歌词来源」中连接 Apple Music 账号后，即可使用 Apple Music 官方歌词，多数歌曲带逐字时间轴。需要 Apple Music 订阅。

- 默认关闭
- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-matching"></a>

### 智能匹配

默认对各歌词源的结果评分，按歌名、歌手、时长和版本（现场版、伴奏等）选出与当前播放歌曲最吻合的一份。也可改为「顺序优先」：不评分，按你设定的顺序采用第一个有结果的歌词源。

- 设置位置：歌词 › 获取 › 匹配算法

<a id="feature-auto-upgrade"></a>

### 匹配规则更新后重新选择

新版本改进匹配算法或评分规则后，在后台重新评估已有歌词，有更合适的版本时自动替换。关闭后，歌词一经选定不再自动更换。

- 默认开启
- 设置位置：歌词 › 获取 › 随匹配算法更新重新选择

<a id="feature-prefetch"></a>

### 预先获取后续歌曲的歌词

读取播放器的播放队列，预先为接下来的几首歌曲获取歌词；无法读取队列时，优先获取同一专辑中的其他歌曲。QQ 音乐、网易云音乐、酷狗音乐、汽水音乐和 VOX 的队列需要「完全磁盘访问权限」才能读取。

- 默认开启
- 设置位置：歌词 › 获取 › 预解析待播曲目
- 设置位置：播放器 › 权限与服务 › 完全磁盘访问权限

<a id="feature-player-local-lyrics"></a>

### 直接使用播放器保存在本机的歌词

Apple Music、Spotify、酷狗音乐、KKBOX、Amazon Music 和洛雪音乐保存在本机的歌词可直接使用，与播放器显示的版本一致，速度也更快（Apple Music 和 Spotify 只有在播放器中显示过歌词的歌曲才有）；QQ 音乐和网易云音乐按本机曲库认出正在播放的是哪一首，省去搜索，直接取用同一版本的歌词；reAMP、VOX 和 Pine Player 播放时，以及 Apple Music 播放资料库中的本地文件、洛雪音乐播放本地列表中的歌曲时，使用文件内嵌的歌词或同名 .lrc 文件。QQ 音乐、网易云音乐、酷狗音乐需要在系统设置中为 Lyrimuse 开启「完全磁盘访问权限」；未授权时仍可联网查找歌词。

- 默认关闭
- 设置位置：播放器 › 权限与服务 › 完全磁盘访问权限

<a id="feature-lock-hand-picked"></a>

### 锁定手选歌词

开启后，从搜索结果中手动选择的歌词将被锁定，之后的自动匹配和重新匹配均不会替换。

- 默认关闭
- 设置位置：歌词 › 获取 › 锁定手选歌词

<a id="feature-lyrics-manager"></a>

### 歌词管理窗口

浏览、编辑、删除或重新搜索任意歌曲的歌词，支持多选批量删除，并可一次清理广告和播客留下的空记录。时间轴不准的歌曲可单独调整偏移。尚无歌词的歌曲可一键全部重试，整个歌词库也可按当前规则重新匹配（每首之间的间隔可调），手动修改过的歌词不受影响。

- 设置位置：歌词 › 管理 › 歌词库
- 设置位置：歌词 › 管理 › 自动匹配缺失歌词
- 设置位置：歌词 › 管理 › 重新匹配整个歌词库
- 设置位置：快捷键 › 打开歌词管理
- 设置位置：歌词 › 管理 › 扫描间隔

<a id="feature-song-entries"></a>

### 同曲条目：同一首歌曲共用歌词

同一首歌在不同播放器、不同专辑版本中的条目会被识别为同一首：各条目共用一份歌词，手动修改和时间轴校准同步生效，播放次数合并统计。在歌词管理中打开「同曲条目」可逐行对比各条目的歌词，识别有误的条目可拆分，之后也可恢复合并。关闭共用后，各条目分别匹配歌词。

- 默认开启
- 设置位置：歌词 › 获取 › 同曲条目共用歌词

<a id="feature-fix-lyrics"></a>

### 随时更换、修改歌词

在歌词窗口的「⋯」菜单中搜索其他歌词、重新自动匹配，或在外部文本编辑器中修改。编辑逐字歌词时只修改文字，每个字的时间保持不变。

- 设置位置：快捷键 › 搜索歌词

<a id="feature-offline"></a>

### 离线可用，歌词以 .lrc 文件保存

已找到的歌词均缓存在本机，离线时也能显示。每首歌曲保存一份 .lrc，有译文、读音时另存 .tr.lrc 和 .roma.lrc，逐字时间轴默认存为 .yrc，也可改存 TTML、增强 LRC、QRC 或 KRC。默认位于 ~/Library/Application Support/me.yudaotor.lyrimuse/lyrics/，位置可更改。

- 设置位置：歌词 › 管理 › 歌词文件夹
- 设置位置：歌词 › 管理 › 逐字歌词格式

## 译文、读音与歌词处理

<a id="feature-translation"></a>

### 译文

歌词源自带的译文显示在原文下方。网易云音乐、QQ 音乐、酷狗的译文为中文；Musixmatch 和机器翻译按所选译文语言提供，共 17 种可选。悬浮歌词、歌词窗口、灵动岛、菜单栏、触控栏可分别设置是否显示。系统语言包含中文时默认显示。

- 设置位置：歌词 › 译文 › 译文语言
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 译文
- 设置位置：快捷键 › 显示/隐藏译文

<a id="feature-machine-translation"></a>

### 无译文时自动翻译

歌词源未提供译文时使用机器翻译。在 macOS 15 及以上且已下载翻译语言包时，由 macOS 自带的 Apple 翻译在本机完成，歌词不离开本机；无法在本机翻译时，将待翻译的歌词发送至谷歌翻译，仍不可用时改用 MyMemory。翻译语言包可在同一张卡片中下载。

- 默认关闭
- 设置位置：歌词 › 译文 › 无译文时自动翻译
- 设置位置：歌词 › 译文 › 翻译语言包

<a id="feature-romanization"></a>

### 读音标注

日语罗马音、韩语罗马字、普通话拼音、粤语粤拼，逐词标注在歌词上方；俄语、泰语、希腊语、印地语等十八种语言按各语言的官方体系或 ISO 标准标注。按行判断语言：中文歌曲中夹有一句日文时，只为该句标注。标注哪些语言可在此处选择，中文界面默认不标注普通话拼音。各显示位置可分别设置是否显示。

- 默认开启
- 设置位置：歌词 › 调整 › 标注读音的语言
- 设置位置：歌词 › 调整 › 日语读音
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 读音
- 设置位置：快捷键 › 显示/隐藏读音

<a id="feature-chinese-script"></a>

### 简繁转换

将中文歌词统一显示为简体或繁体，与 App 界面语言无关。

- 设置位置：歌词 › 调整 › 繁简转换

<a id="feature-split-join-lines"></a>

### 长句拆分、短句合并

悬浮歌词、灵动岛、菜单栏和触控栏按各自的可用宽度，将放不下的长句拆分为多句，将一闪而过的短句合并为一句。歌词窗口仍按一句一行显示。两项各有独立开关。

- 默认关闭
- 设置位置：歌词 › 调整 › 长句拆分
- 设置位置：歌词 › 调整 › 短句合并

<a id="feature-timing-offset"></a>

### 时间轴偏移

整体提前或延后歌词，可仅对某个播放器生效。单首歌曲可在歌词管理中单独调整；也可通过快捷键随时提前、延后或归零。

- 设置位置：歌词 › 调整 › 时间轴偏移
- 设置位置：快捷键 › 歌词提前
- 设置位置：快捷键 › 歌词延后
- 设置位置：快捷键 › 歌词偏移归零

## 歌词显示位置与外观

<a id="feature-floating-lyrics"></a>

### 桌面悬浮歌词

浮于所有窗口之上、始终置顶的歌词，逐字高亮。可拖动到任意位置，也可固定在屏幕顶部居中或 Dock 上方居中。连接多台显示器时，可固定在其中一台，也可跟随当前使用的窗口切换到其所在的显示器。可同时显示读音、译文和下一句。

- 默认开启
- 设置位置：歌词显示 › 悬浮歌词 › 桌面悬浮歌词
- 设置位置：歌词显示 › 悬浮歌词 › 位置
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 下一句
- 设置位置：快捷键 › 显示/隐藏悬浮歌词
- 设置位置：歌词显示 › 悬浮歌词 › 所在屏幕

<a id="feature-notch-lyrics"></a>

### 灵动岛歌词

紧贴屏幕顶部刘海的胶囊，没有刘海的 Mac 和外接显示器上同样可用。左右两侧可分别显示歌名、歌手、专辑、封面、播放控制、已播放或剩余时长，旁边是随音乐跳动的音浪。指针悬停时展开，提供播放控制、进度条、歌词校准，以及喜欢、搜索歌词等快捷按钮。播放广告时显示剩余时长。

- 默认关闭
- 设置位置：歌词显示 › 灵动岛 › 灵动岛歌词
- 设置位置：歌词显示 › 灵动岛 › 风格
- 设置位置：歌词显示 › 灵动岛 › 屏幕
- 设置位置：歌词显示 › 灵动岛 › 左耳
- 设置位置：快捷键 › 显示/隐藏灵动岛歌词
- 设置位置：快捷键 › 临时展开灵动岛
- 设置位置：歌词显示 › 灵动岛 › 展开态 › 快捷操作

<a id="feature-menu-bar-lyrics"></a>

### 菜单栏歌词

当前歌词直接显示在菜单栏中，过长时滚动显示，不会被截断。可增加一行显示下一句、译文或读音。也可显示在菜单栏中间，有刘海时紧挨着刘海；或者只显示歌名，可带上歌手。

- 默认关闭
- 设置位置：歌词显示 › 菜单栏 › 菜单栏歌词
- 设置位置：歌词显示 › 菜单栏 › 布局 › 歌词位置
- 设置位置：歌词显示 › 菜单栏 › 布局 › 显示内容
- 设置位置：歌词显示 › 菜单栏 › 布局 › 副行
- 设置位置：快捷键 › 显示/隐藏菜单栏歌词

### 十三款播放器，可多选或自动识别

### 按需申请权限

Apple Music、Spotify、Kaset 和 VOX 需要「自动化」权限才能读取播放状态；QQ 音乐、网易云音乐、酷狗音乐需要「完全磁盘访问权限」才能使用本机歌词和播放队列，汽水音乐和 VOX 需要该权限读取播放队列；Amazon Music 和 Pine Player 的进度校准，Pine Player 的播放列表，QQ 音乐、网易云音乐、酷狗音乐、汽水音乐、Amazon Music、reAMP 和 Pine Player 的随机、循环、喜欢按钮，以及其他 App 占用「正在播放」时 QQ 音乐、网易云音乐、汽水音乐和 Pine Player 的播放按钮，需要「辅助功能」权限；浏览器中的网页播放器需要为浏览器开启「自动化」权限，并在浏览器中开启「允许 Apple 事件中的 JavaScript」。其他播放器无需权限。设置中会标明每项的当前授权状态。

## 收听记录、Last.fm 与分享

<a id="feature-lastfm"></a>

### Last.fm 打卡与收听档案

一键连接 Last.fm，无需复制 token。可查看今日、近 7 天和累计收听次数，歌手、专辑、歌曲榜单及排名变化；「足迹」中提供全年热力图（点按某一天可查看当天收听最多的歌曲）、收听时段、常听歌手的国家和地区以及「那年今日」。最近播放中的每首歌曲都可点按红心标记喜欢。

- 默认关闭
- 设置位置：Last.fm › 设置 › Scrobble 规则

<a id="feature-scrobble-rules"></a>

### 自定义打卡规则

可设置播放到 50%、75%、90% 或完整播放后才计为一次；可设置是否计入短于 30 秒的歌曲；默认将合唱署名、繁简写法和「- Single」等后缀对齐到 Last.fm 的正式条目，也可按原样发送；还可将某个播放器整体排除在 Last.fm 之外。

- 设置位置：Last.fm › 设置 › Scrobble 时机
- 设置位置：Last.fm › 设置 › 短于 30 秒的曲目
- 设置位置：Last.fm › 设置 › 匹配模式
- 设置位置：Last.fm › 设置 › Scrobble 的播放器

<a id="feature-local-log"></a>

### 每次播放先记录在本机

### 同步到 ListenBrainz

每次播放基于同一份播放状态分别发送到 Last.fm 和 ListenBrainz，两边记录一致。还可将 iPhone 通过 Last.fm 记录的播放导入 ListenBrainz。位于侧栏的「实验室」中。

## 全部设置项

设置窗口里的每一项，按所在位置列出，共 291 项。在设置窗口侧栏顶部的搜索框里输入名称，可以直接跳到那一项。

### 歌词 › 获取

- **歌词来源**
- **匹配算法**
- **随匹配算法更新重新选择**：开（默认）：匹配算法或评分规则更新后，会在后台重新评估已有歌词，并可能更换为更合适的版本；关：歌词确定后不再自动更换；首次解析、手动重新搜索和手动编辑不受影响
- **同曲条目共用歌词**：开（默认）：同一首歌在不同播放器、不同专辑版本下、可确认为同一录音的条目使用同一份歌词，手动修改一并同步；关：各条目分别匹配歌词，已同步的条目恢复为原来的歌词
- **预解析待播曲目**
- **锁定手选歌词**：关（默认）：仅替换本次歌词，之后的自动搜索或评分变化仍可能再次替换；开：锁定这首歌曲的歌词，自动匹配不再更改；开启后，此前手动选定的歌曲一并锁定（已被自动替换的除外）
