# Lyrimuse 功能清单

[English](feature-list.md) · 简体中文 · [繁體中文](feature-list.zh-Hant.md)

Lyrimuse 是 macOS 上的开源（GPL-3.0）逐字歌词 App，支持 macOS 14 及以上、Apple Silicon 和 Intel 芯片。它给 Apple Music、Spotify、QQ 音乐、网易云音乐、酷狗音乐、汽水音乐、KKBOX、Amazon Music、Kaset，以及浏览器里的 YouTube Music 和 Spotify 网页版显示逐字同步的歌词：桌面悬浮歌词、灵动岛、菜单栏、触控栏和歌词窗口都能显示，带翻译和读音标注（拼音、粤拼、日语罗马音、韩语罗马字），还能打卡到 Last.fm 和 ListenBrainz、在 Discord 上显示正在听的歌。界面有简体中文、繁体中文和英文。

这份清单列出 Lyrimuse 的每一项功能：做什么、在设置的哪里、装好后默认开着还是关着；最后附上设置窗口里的全部设置项。清单跟代码一起维护，功能有增减时同步更新。

## 找歌词

<a id="feature-lyric-sources"></a>

### 十四个歌词源自动查找

网易云音乐、QQ 音乐、酷狗、酷我、咪咕、Musixmatch、LRCLIB、LyricFind、Deezer、AMLL、汽水音乐、VIBE、Genie 和 Apple Music。每个源都可以单独开关、调整顺序，或者测一下现在能不能连上。

- 默认开启
- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-apple-music-lyrics"></a>

### Apple Music 官方歌词

在「歌词来源」里连上 Apple Music 账号以后，就能用 Apple Music 自己的歌词，很多歌带逐字时间轴。需要 Apple Music 订阅。

- 默认关闭
- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-matching"></a>

### 智能匹配

默认给每个源找到的结果打分，按歌名、歌手、时长和版本（现场版、伴奏等）挑出跟正在放的这首最对得上的一份。也可以改成「顺序优先」：不打分，按你排的顺序用第一个有结果的源。

- 设置位置：歌词 › 获取 › 匹配算法

<a id="feature-auto-upgrade"></a>

### 匹配规则更新后重新挑选

新版本改进了匹配算法或评分规则后，在后台重新评估已经找到的歌词，有更合适的版本就换上。关掉以后歌词定下来就不再自动更换。

- 默认开启
- 设置位置：歌词 › 获取 › 随匹配算法更新重新选择

<a id="feature-prefetch"></a>

### 提前找好下几首的歌词

读播放器的播放队列，提前给接下来要放的几首找好歌词；读不到队列时，先找同一张专辑里的其它歌。QQ 音乐、网易云音乐、酷狗音乐和汽水音乐的队列要「完全磁盘访问权限」才能读。

- 默认开启
- 设置位置：歌词 › 获取 › 预解析待播曲目
- 设置位置：播放器 › 权限与服务 › 完全磁盘访问权限

<a id="feature-player-local-lyrics"></a>

### 直接用播放器存在本机的歌词

QQ 音乐、网易云音乐、酷狗音乐、KKBOX、Amazon Music 和洛雪音乐自己存下的歌词，Lyrimuse 可以直接拿来用，跟播放器显示的是同一版，也更快；reAMP 放歌时用文件里自带的歌词或同名的 .lrc 文件。QQ 音乐、网易云音乐、酷狗音乐这三家要在系统设置里给 Lyrimuse「完全磁盘访问权限」；不给也能联网查歌词。

- 默认关闭
- 设置位置：播放器 › 权限与服务 › 完全磁盘访问权限

<a id="feature-source-health"></a>

### 歌词源出问题时提醒你

某个歌词源最近几乎找不到歌词、比平时少很多、经常出错或连不上时，「歌词来源」里它旁边会出现提醒，点开能看到依据的次数和比例。其它源照常在找，统计只在本机做。

- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-lock-hand-picked"></a>

### 锁定手选歌词

打开后，你从搜索结果里手动选的歌词会被锁定，以后的自动匹配和重新匹配都不会换掉它。

- 默认关闭
- 设置位置：歌词 › 获取 › 锁定手选歌词

<a id="feature-lyrics-manager"></a>

### 歌词管理窗口

浏览、手改、删除、重新搜索任意一首的歌词，可以多选批量删，广告和播客留下的空记录也能一次清掉。某首歌时间对不上，可以单独给它调偏移。还没找到歌词的歌可以一键全部重试，整个歌词库也能按现在的规则重新匹配一遍（每首之间的间隔可调），你手改过的不会被动。

- 设置位置：歌词 › 管理 › 歌词库
- 设置位置：歌词 › 管理 › 自动匹配缺失歌词
- 设置位置：歌词 › 管理 › 重新匹配整个歌词库
- 设置位置：快捷键 › 打开歌词管理
- 设置位置：歌词 › 管理 › 扫描间隔

<a id="feature-song-entries"></a>

### 同曲条目：同一首歌共用歌词

同一首歌在不同播放器、不同专辑版本下会被认成同一首：各条目共用一份歌词，手改和校准一起同步，播放次数合并统计。在歌词管理里打开「同曲条目」，能逐行对比各条目的歌词，认错了的可以拆开，之后也能恢复合并。不想共用就关掉，各条目分别匹配。

- 默认开启
- 设置位置：歌词 › 获取 › 同曲条目共用歌词

<a id="feature-fix-lyrics"></a>

### 当场换歌词、改歌词

在歌词窗口的「⋯」菜单里搜别的歌词、重新自动匹配，或者用你自己的文本编辑器改。改逐字歌词时只改字，每个字的时间不动。

- 设置位置：快捷键 › 搜索歌词

<a id="feature-offline"></a>

### 离线也能看，歌词就是 .lrc 文件

找到过的歌词都缓存在本机，不联网也能显示。每首都有一份 .lrc，有译文、读音的另有 .tr.lrc 和 .roma.lrc，逐字时间轴存成 .yrc。默认放在 ~/.config/lyrimuse/lyrics/，位置可以改。

- 设置位置：歌词 › 管理 › 歌词文件夹

<a id="section-text"></a>

## 译文、读音与歌词处理

<a id="feature-translation"></a>

### 译文

歌词源自带的译文显示在原文下面。网易云音乐、QQ 音乐、酷狗的译文是中文；Musixmatch 和机器翻译按你选的译文语言来，有 17 种可选。悬浮歌词、歌词窗口、灵动岛、菜单栏、触控栏各自决定显不显示。读中文的用户默认显示。

- 设置位置：歌词 › 译文 › 译文语言
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 译文
- 设置位置：快捷键 › 显示/隐藏译文

<a id="feature-machine-translation"></a>

### 没有译文时机器翻译

歌词源没有译文时用机器翻译。macOS 15 及以上、下好了翻译语言包时，用 macOS 自带的 Apple 翻译在本机翻，歌词不出本机；本机翻不了时，把要翻的歌词发给谷歌翻译，再不行用 MyMemory。翻译语言包在这里下载。

- 默认关闭
- 设置位置：歌词 › 译文 › 无译文时自动翻译
- 设置位置：歌词 › 译文 › 翻译语言包

<a id="feature-romanization"></a>

### 读音标注

日语罗马音、韩语罗马字、普通话拼音、粤语粤拼，逐词标在歌词上面。一行一行判断语言：中文歌里夹了一句日文，就只给那一句标。标哪几种语言在这里选，中文界面默认不标普通话拼音。各展示面单独决定显不显示。

- 默认开启
- 设置位置：歌词 › 调整 › 标注读音的语言
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 读音
- 设置位置：快捷键 › 显示/隐藏读音

<a id="feature-chinese-script"></a>

### 简繁转换

把中文歌词统一显示成简体或繁体，跟 App 界面用什么语言无关。

- 设置位置：歌词 › 调整 › 繁简转换

<a id="feature-split-join-lines"></a>

### 长句拆分、短句合并

悬浮歌词、灵动岛、菜单栏和触控栏按自己一行能放多宽，把放不下的长句拆成几句、把一闪而过的短句并成一句。歌词窗口照旧一句一行。两个开关分开。

- 默认关闭
- 设置位置：歌词 › 调整 › 长句拆分
- 设置位置：歌词 › 调整 › 短句合并

<a id="feature-timing-offset"></a>

### 调时间轴

歌词整体提前或延后，可以只对某个播放器生效。单首歌在歌词管理里另调；也可以绑快捷键随时提前、延后、归零。

- 设置位置：歌词 › 调整 › 时间轴偏移
- 设置位置：快捷键 › 歌词提前
- 设置位置：快捷键 › 歌词延后
- 设置位置：快捷键 › 歌词偏移归零

## 歌词显示在哪里、长什么样

<a id="feature-floating-lyrics"></a>

### 桌面悬浮歌词

浮在所有窗口上面、一直置顶的歌词，逐字高亮。拖到哪儿停在哪儿，也可以固定在屏幕顶部居中或 Dock 上方居中。接了几块屏幕时，可以固定在一块上，也可以跟着你正在用的窗口换到它所在的那块。可以同时显示读音、译文和下一句。

- 默认开启
- 设置位置：歌词显示 › 悬浮歌词 › 桌面悬浮歌词
- 设置位置：歌词显示 › 悬浮歌词 › 位置
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 下一句
- 设置位置：快捷键 › 显示/隐藏悬浮歌词
- 设置位置：歌词显示 › 悬浮歌词 › 所在屏幕

<a id="feature-notch-lyrics"></a>

### 灵动岛歌词

贴在屏幕顶部刘海旁的胶囊，没有刘海的 Mac 和外接显示器上也能用。左右两边各放一样：歌名、歌手、专辑、封面、播放控制、已播或剩余时长，旁边是跟着音乐跳的音浪。鼠标移上去展开，有播放控制、进度条、歌词校准，以及喜欢、搜索歌词这些快捷按钮。放广告时显示还剩多久。

- 默认关闭
- 设置位置：歌词显示 › 灵动岛 › 灵动岛歌词
- 设置位置：歌词显示 › 灵动岛 › 风格
- 设置位置：歌词显示 › 灵动岛 › 屏幕
- 设置位置：歌词显示 › 灵动岛 › 左耳
- 设置位置：快捷键 › 显示/隐藏灵动岛歌词
- 设置位置：歌词显示 › 灵动岛 › 展开态 › 快捷操作

<a id="feature-menu-bar-lyrics"></a>

### 菜单栏歌词

当前这句直接显示在菜单栏上，太长会滚动，不会截成半句。可以多加一行显示下一句、译文或读音。

- 默认关闭

- 设置位置：歌词显示 › 菜单栏 › 布局 › 副行
- 设置位置：快捷键 › 显示/隐藏菜单栏歌词

<a id="feature-touch-bar-lyrics"></a>

### 触控栏歌词

带触控栏的 MacBook Pro 上，当前这句在触控栏上跟着唱到的地方滚动，还可以显示封面和播放控制。歌词可以是白色、跟随封面或自选颜色，没唱到的部分亮度可调。可以开始播放时自动展开、暂停时自动收起；「更多」键里有歌词校准、喜欢、随机和循环、音量和播放进度。

- 默认关闭
- 设置位置：歌词显示 › 触控栏 › 触控栏歌词
- 设置位置：快捷键 › 展开/收起触控栏歌词
- 设置位置：歌词显示 › 触控栏 › 样式 › 歌词颜色
- 设置位置：歌词显示 › 触控栏 › 行为 › 开始播放时自动展开
- 设置位置：歌词显示 › 触控栏 › 布局 › 显示「更多」键

<a id="feature-lyrics-window"></a>

### 歌词窗口

照着 Apple Music 歌词页做的整页歌词：模糊的封面铺底，整首跟着滚到当前这句；对唱按歌手分开，和声单独一行，拖长音的词会放大发光。背景可以跟随封面、纯色、渐变或毛玻璃，文字的粗细、已唱颜色和对齐方式也能调。从菜单栏图标或快捷键打开。

- 设置位置：歌词显示 › 歌词窗口 › 歌词窗口
- 设置位置：歌词显示 › 歌词窗口 › 背景 › 背景
- 设置位置：快捷键 › 打开歌词窗口
- 设置位置：歌词显示 › 歌词窗口 › 布局 › 对齐方式

## 播放器与播放控制

<a id="feature-players"></a>

### 十一个播放器，可多选或自动识别

Apple Music、Spotify、QQ 音乐、网易云音乐、酷狗音乐、汽水音乐、洛雪音乐、KKBOX、Amazon Music、仿 Winamp 的 reAMP，以及 YouTube Music 客户端 Kaset。可以同时选几个，也可以留在自动识别，跟着 macOS「正在播放」里的那个走。Apple Music 电台也能用，主播说话时显示电台名和台标。

- 设置位置：播放器 › 音乐 App

<a id="feature-web-players"></a>

### 浏览器里的 YouTube Music、Spotify 网页版

把常用的浏览器配对一次，网页里放的歌也有歌词，按网页自己的进度走。带一键自检，先告诉你这个浏览器能不能被控制。放广告时灵动岛会显示还剩多久、这是第几条。

- 默认关闭
- 设置位置：播放器 › 网页版

<a id="feature-skip-youtube-ads"></a>

### 自动跳过 YouTube Music 广告

浏览器里的 YouTube Music 一出现「跳过」按钮就替你点掉。不开也能在灵动岛上手动点跳过。需要「辅助功能」权限。

- 默认关闭
- 设置位置：播放器 › 网页版 › 自动跳过 YouTube Music 广告
- 设置位置：播放器 › 权限与服务 › 辅助功能权限

<a id="feature-other-players"></a>

### 别的播放器也能加

不在列表里的播放器，可以从「应用程序」里选它加进信任列表；有没见过的播放器在放歌时也会提醒你要不要加。

- 设置位置：播放器 › 其他 App
- 设置位置：播放器 › 添加 App…
- 设置位置：播放器 › 新播放器提醒

<a id="feature-permissions"></a>

### 按需要的权限

Apple Music、Spotify 和 Kaset 要「自动化」权限才能读播放状态；QQ 音乐、网易云音乐、酷狗音乐要「完全磁盘访问权限」才能用本机歌词和播放队列，汽水音乐要它读播放队列；Amazon Music 校准进度，QQ 音乐、网易云音乐、酷狗音乐、汽水音乐、Amazon Music 和 reAMP 的随机、循环、喜欢键，以及别的 App 占着「正在播放」时 QQ 音乐、网易云音乐和汽水音乐的播放键，要「辅助功能」权限；浏览器里的网页播放器要给浏览器「自动化」权限，并在浏览器里打开「允许 Apple 事件中的 JavaScript」。其余播放器不需要权限。设置里每一项都标着现在授权了没有。

- 设置位置：播放器 › 权限与服务 › 自动化权限
- 设置位置：播放器 › 权限与服务 › 完全磁盘访问权限
- 设置位置：播放器 › 权限与服务 › 辅助功能权限

### 播放控制、拖进度条

在歌词窗口和展开的灵动岛上播放、暂停、切歌，拖进度条跳转。随机、循环、喜欢和音量看播放器支持：Apple Music、Spotify、Kaset、QQ 音乐、Amazon Music 和浏览器里的 YouTube Music 各支持其中几项或全部，网易云音乐、酷狗音乐、汽水音乐和洛雪音乐有喜欢，洛雪在它的设置里打开开放 API 后还能调音量。播放、暂停、切歌和喜欢也能绑全局快捷键。浏览器视频这类 App 占着系统的「正在播放」时，QQ 音乐、网易云音乐和汽水音乐的播放、暂停和切歌改按它们自己的菜单或播放条，这时不能拖进度跳转。

- 设置位置：歌词显示 › 灵动岛 › 展开态 › 显示播放控制
- 设置位置：快捷键 › 播放/暂停
- 设置位置：快捷键 › 下一首
- 设置位置：快捷键 › 上一首
- 设置位置：快捷键 › 喜欢/取消喜欢
- 设置位置：播放器 › 权限与服务 › 洛雪音乐开放 API

## 听歌记录、Last.fm 与分享

<a id="feature-lastfm"></a>

### Last.fm 打卡与听歌档案

一键连上 Last.fm（不用复制 token）。看今天、近 7 天和一共听了多少，歌手、专辑、歌曲榜单和升降，「足迹」里有全年热力图（点某一天能看那天听得最多的歌）、收听时段、常听歌手的国家和地区和「那年今日」。最近播放里每首都能点红心。

- 默认关闭
- 设置位置：Last.fm › 设置 › Scrobble 规则

<a id="feature-scrobble-rules"></a>

### 打卡规则你来定

听到 50%、75%、90% 或整首放完才算一次；短于 30 秒的歌要不要算；默认把合唱署名、简繁写法、「- Single」这类尾巴对齐到 Last.fm 的正式条目，也可以原样发送；还能把某个播放器整个排除在 Last.fm 外面。

- 设置位置：Last.fm › 设置 › Scrobble 时机
- 设置位置：Last.fm › 设置 › 短于 30 秒的曲目
- 设置位置：Last.fm › 设置 › 匹配模式
- 设置位置：Last.fm › 设置 › Scrobble 的播放器

<a id="feature-local-log"></a>

### 每次播放先记在本地

没连 Last.fm 时听的歌先记在本机，连上以后在 Last.fm 页「待补交的收听」里点「补交」传上去。连着时某次可能没传上去的，会自动去 Last.fm 核对、补交。Last.fm 只收大约两周内的记录。

<a id="feature-listenbrainz"></a>

### 同步到 ListenBrainz

每次播放用同一份播放状态分别发给 Last.fm 和 ListenBrainz，两边对得上。还可以把 iPhone 上经 Last.fm 记下的播放转进 ListenBrainz。在侧栏的「实验室」里。

- 默认关闭
- 设置位置：实验室 › ListenBrainz › 账号信息

<a id="feature-discord"></a>

### 在 Discord 上显示正在听的歌

资料卡和好友列表里显示播放器、歌名、歌手、封面和进度条，点歌名、歌手打开播放器网站上的页面。专辑那一行可以换成正在唱的这句，资料卡底下还能加最多两个按钮。文字怎么排、哪些播放器算、暂停时留不留、封面角上放什么图标都能选；也可以只显示在用哪个播放器、不说是哪首歌，或者暂时隐藏一段时间。

- 默认关闭
- 设置位置：Discord › 在 Discord 上显示
- 设置位置：Discord › 显示哪些播放器
- 设置位置：Discord › 暂停后
- 设置位置：Discord › 暂时隐藏
- 设置位置：Discord › 显示内容
- 设置位置：Discord › 按钮
- 设置位置：Discord › 隐藏歌曲信息

### 歌词 › 获取

- **歌词来源**
- **匹配算法**
- **随匹配算法更新重新选择**：开（默认）：匹配算法或评分规则更新后，会在后台重新评估已有歌词，并可能更换为更合适的版本；关：歌词确定后不再自动更换；首次解析、手动重新搜索和手动编辑不受影响
- **同曲条目共用歌词**：开（默认）：同一首歌在不同播放器、不同专辑版本下、可确认为同一录音的条目使用同一份歌词，手动修改一并同步；关：各条目分别匹配歌词，已同步的条目恢复为原来的歌词
- **预解析待播曲目**
- **锁定手选歌词**：关（默认）：仅替换本次歌词，之后的自动搜索或评分变化仍可能再次替换；开：锁定这首歌曲的歌词，自动匹配不再更改；开启后，此前手动选定的歌曲一并锁定（已被自动替换的除外）
