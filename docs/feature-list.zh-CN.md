# Lyrimuse 功能清单

[English](feature-list.md) · 简体中文 · [繁體中文](feature-list.zh-Hant.md)

Lyrimuse 是 macOS 上的开源（GPL-3.0）逐字歌词 App，支持 macOS 14 及以上、Apple Silicon 和 Intel 芯片。它给 Apple Music、Spotify、QQ 音乐、网易云音乐、酷狗音乐、汽水音乐、KKBOX、Amazon Music、Kaset，以及浏览器里的 YouTube Music 和 Spotify 网页版显示逐字同步的歌词：桌面悬浮歌词、灵动岛、菜单栏、触控栏和歌词窗口都能显示，带翻译和读音标注（拼音、粤拼、日语罗马音、韩语罗马字），还能打卡到 Last.fm 和 ListenBrainz、在 Discord 上显示正在听的歌。界面有简体中文、繁体中文和英文。

这份清单列出 Lyrimuse 的每一项功能：做什么、在设置的哪里、装好后默认开着还是关着；最后附上设置窗口里的全部设置项。清单跟代码一起维护，功能有增减时同步更新。

## 找歌词

<a id="feature-lyric-sources"></a>

### 十二个歌词源自动查找

网易云音乐、QQ 音乐、酷狗、酷我、咪咕、Musixmatch、LRCLIB、LyricFind、Deezer、AMLL、汽水音乐和 Apple Music。每个源都可以单独开关、调整顺序，或者测一下现在能不能连上。

- 默认开启
- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-apple-music-lyrics"></a>

### Apple Music 官方歌词

在「歌词来源」里连上 Apple Music 账号以后，就能用 Apple Music 自己的歌词，很多歌带逐字时间轴。需要 Apple Music 订阅。

- 默认关闭
- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-matching"></a>

### 智能匹配

默认给每个源找到的结果打分，按歌名、歌手、时长和版本（现场版、伴奏等）挑出跟正在放的这首最对得上的一份。也可以改成「顺序优先」：不打分，按你排的顺序用第一个有结果的源。

- 设置位置：歌词 › 获取 › 匹配算法

<a id="feature-auto-upgrade"></a>

### 匹配规则更新后重新挑选

新版本改进了匹配算法或评分规则后，在后台重新评估已经找到的歌词，有更合适的版本就换上。关掉以后歌词定下来就不再自动更换。

- 默认开启
- 设置位置：歌词 › 获取 › 随匹配算法更新重新选择

<a id="feature-prefetch"></a>

### 提前找好下几首的歌词

读播放器的播放队列，提前给接下来要放的几首找好歌词；读不到队列时，先找同一张专辑里的其它歌。QQ 音乐、网易云音乐、酷狗音乐的队列要「完全磁盘访问权限」才能读。

- 默认开启
- 设置位置：歌词 › 获取 › 预解析待播曲目
- 设置位置：播放器 › 完全磁盘访问权限

<a id="feature-player-local-lyrics"></a>

### 直接用播放器存在本机的歌词

QQ 音乐、网易云音乐和酷狗音乐自己下载过的歌词，Lyrimuse 可以直接拿来用，跟播放器显示的是同一版，也更快。需要在系统设置里给 Lyrimuse「完全磁盘访问权限」；不给也能联网查歌词。

- 默认关闭
- 设置位置：播放器 › 完全磁盘访问权限

<a id="feature-source-health"></a>

### 歌词源出问题时提醒你

某个歌词源最近几乎找不到歌词、比平时少很多、经常出错或连不上时，「歌词来源」里它旁边会出现提醒，点开能看到依据的次数和比例。其它源照常在找，统计只在本机做。

- 设置位置：歌词 › 获取 › 歌词来源

<a id="feature-lock-hand-picked"></a>

### 锁定手选歌词

打开后，你从搜索结果里手动选的歌词会被锁定，以后的自动匹配和重新匹配都不会换掉它。

- 默认关闭
- 设置位置：歌词 › 获取 › 锁定手选歌词

<a id="feature-lyrics-manager"></a>

### 歌词管理窗口

浏览、手改、删除、重新搜索任意一首的歌词，可以多选批量删，广告和播客留下的空记录也能一次清掉。某首歌时间对不上，可以单独给它调偏移。还没找到歌词的歌可以一键全部重试，整个歌词库也能按现在的规则重新匹配一遍，你手改过的不会被动。

- 设置位置：歌词 › 管理 › 歌词库
- 设置位置：歌词 › 管理 › 自动匹配缺失歌词
- 设置位置：歌词 › 管理 › 重新匹配整个歌词库
- 设置位置：快捷键 › 打开歌词管理

<a id="feature-fix-lyrics"></a>

### 当场换歌词、改歌词

在歌词窗口的「⋯」菜单里搜别的歌词、重新自动匹配，或者用你自己的文本编辑器改。改逐字歌词时只改字，每个字的时间不动。

- 设置位置：快捷键 › 搜索歌词

<a id="feature-offline"></a>

### 离线也能看，歌词就是 .lrc 文件

找到过的歌词都缓存在本机，不联网也能显示。每首都有一份 .lrc，有译文、读音的另有 .tr.lrc 和 .roma.lrc，逐字时间轴存成 .yrc。默认放在 ~/.config/lyrimuse/lyrics/，位置可以改。

- 设置位置：歌词 › 管理 › 歌词文件夹

<a id="section-text"></a>

## 译文、读音与歌词处理

<a id="feature-translation"></a>

### 译文

歌词源自带的译文显示在原文下面。网易云音乐、QQ 音乐、酷狗的译文是中文；Musixmatch 和机器翻译按你选的译文语言来，有 17 种可选。悬浮歌词、歌词窗口、灵动岛、菜单栏、触控栏各自决定显不显示。读中文的用户默认显示。

- 设置位置：歌词 › 译文 › 译文语言
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 译文
- 设置位置：快捷键 › 显示/隐藏译文

<a id="feature-machine-translation"></a>

### 没有译文时机器翻译

歌词源没有译文时用机器翻译。macOS 15 及以上、下好了翻译语言包时，用 macOS 自带的 Apple 翻译在本机翻，歌词不出本机；本机翻不了时，把要翻的歌词发给谷歌翻译，再不行用 MyMemory。翻译语言包在这里下载。

- 默认关闭
- 设置位置：歌词 › 译文 › 系统兜底翻译
- 设置位置：歌词 › 译文 › 翻译语言包

<a id="feature-romanization"></a>

### 读音标注

日语罗马音、韩语罗马字、普通话拼音、粤语粤拼，逐词标在歌词上面。一行一行判断语言：中文歌里夹了一句日文，就只给那一句标。标哪几种语言在这里选，中文界面默认不标普通话拼音。各展示面单独决定显不显示。

- 默认开启
- 设置位置：歌词 › 调整 › 标注读音的语言
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 读音
- 设置位置：快捷键 › 显示/隐藏读音

<a id="feature-chinese-script"></a>

### 简繁转换

把中文歌词统一显示成简体或繁体，跟 App 界面用什么语言无关。

- 设置位置：歌词 › 调整 › 繁简转换

<a id="feature-split-join-lines"></a>

### 长句拆分、短句合并

悬浮歌词、灵动岛、菜单栏和触控栏按自己一行能放多宽，把放不下的长句拆成几句、把一闪而过的短句并成一句。歌词窗口照旧一句一行。两个开关分开。

- 默认关闭
- 设置位置：歌词 › 调整 › 长句拆分
- 设置位置：歌词 › 调整 › 短句合并

<a id="feature-timing-offset"></a>

### 调时间轴

歌词整体提前或延后，可以只对某个播放器生效。单首歌在歌词管理里另调；也可以绑快捷键随时提前、延后、归零。

- 设置位置：歌词 › 调整 › 时间轴偏移
- 设置位置：快捷键 › 歌词提前
- 设置位置：快捷键 › 歌词延后
- 设置位置：快捷键 › 歌词偏移归零

## 歌词显示在哪里、长什么样

<a id="feature-floating-lyrics"></a>

### 桌面悬浮歌词

浮在所有窗口上面、一直置顶的歌词，逐字高亮。拖到哪儿停在哪儿，也可以固定在屏幕顶部居中或 Dock 上方居中。可以同时显示读音、译文和下一句。

- 默认开启
- 设置位置：歌词显示 › 悬浮歌词 › 桌面悬浮歌词
- 设置位置：歌词显示 › 悬浮歌词 › 位置
- 设置位置：歌词显示 › 悬浮歌词 › 内容 › 下一句
- 设置位置：快捷键 › 显示/隐藏悬浮歌词

<a id="feature-notch-lyrics"></a>

### 灵动岛歌词

贴在屏幕顶部刘海旁的胶囊，没有刘海的 Mac 和外接显示器上也能用。左右两边各放一样：歌名、歌手、专辑、封面、播放控制、已播或剩余时长，旁边是跟着音乐跳的音浪。鼠标移上去展开，有播放控制、进度条和歌词校准。放广告时显示还剩多久。

- 默认关闭
- 设置位置：歌词显示 › 灵动岛 › 灵动岛歌词
- 设置位置：歌词显示 › 灵动岛 › 风格
- 设置位置：歌词显示 › 灵动岛 › 屏幕
- 设置位置：歌词显示 › 灵动岛 › 左耳
- 设置位置：快捷键 › 显示/隐藏灵动岛歌词

<a id="feature-menu-bar-lyrics"></a>

### 菜单栏歌词

当前这句直接显示在菜单栏上，太长会滚动，不会截成半句。可以多加一行显示下一句、译文或读音。

- 默认关闭
- 设置位置：歌词显示 › 菜单栏 › 菜单栏歌词
- 设置位置：歌词显示 › 菜单栏 › 布局 › 副行
- 设置位置：快捷键 › 显示/隐藏菜单栏歌词

<a id="feature-touch-bar-lyrics"></a>

### 触控栏歌词

带触控栏的 MacBook Pro 上，当前这句在触控栏上跟着唱到的地方滚动，还可以显示封面和播放控制。

- 默认关闭
- 设置位置：歌词显示 › 触控栏 › 触控栏歌词
- 设置位置：快捷键 › 展开/收起触控栏歌词

<a id="feature-lyrics-window"></a>

### 歌词窗口

照着 Apple Music 歌词页做的整页歌词：模糊的封面铺底，整首跟着滚到当前这句；对唱按歌手分开，和声单独一行，拖长音的词会放大发光。背景可以跟随封面、纯色、渐变或毛玻璃。从菜单栏图标或快捷键打开。

- 设置位置：歌词显示 › 歌词窗口 › 歌词窗口
- 设置位置：歌词显示 › 歌词窗口 › 背景 › 背景
- 设置位置：快捷键 › 打开歌词窗口

<a id="feature-mini-lyrics-window"></a>

### 迷你歌词窗口

歌词窗口缩成一张小卡片：只放当前句、加上下一句，或整页滚动。背景、文字颜色、字体、粗细、已唱颜色和顶部的歌名、封面、时间都单独设置。

- 设置位置：歌词显示 › 歌词窗口 › 布局 › 歌词布局
- 设置位置：快捷键 › 切换迷你 / 完整尺寸

<a id="feature-mini-window-auto-hide"></a>

### 迷你窗口暂停或全屏时隐藏

暂停或没在放歌时迷你窗口自动隐藏，开始播放后重新出现；所在屏幕有 App 全屏（看视频、玩游戏）时也可以自动隐藏。两项各自开关。

- 默认关闭
- 设置位置：歌词显示 › 歌词窗口 › 行为 › 暂停时隐藏
- 设置位置：歌词显示 › 歌词窗口 › 行为 › 全屏时隐藏

<a id="feature-animated-artwork"></a>

### 动态封面

Apple Music 上有动态封面的专辑，完整尺寸的歌词窗口里封面也会动。低电量模式或打开「减弱动态效果」时自动停下。

- 默认开启
- 设置位置：歌词显示 › 歌词窗口 › 封面 › 动态封面

<a id="feature-idle-overview"></a>

### 没在放歌时的听歌总览

没在放歌的时候，歌词窗口显示上次放的那首、从它歌词里挑的一句和「继续播放」。连着 Last.fm 时还显示今天、近 7 天和一共听了多少、近 30 天的走势、「那年今日」和带封面的最近播放。

<a id="feature-look"></a>

### 外观随你改

字体（跟随系统，或导入自己的 .ttf / .otf）、字号、粗细、文字和背景颜色、描边、毛玻璃背景。悬浮歌词有几套配色主题，也可以把自己调的存成主题；文字颜色可以跟着专辑封面变。

- 设置位置：歌词显示 › 悬浮歌词 › 主题 › 配色主题
- 设置位置：歌词显示 › 悬浮歌词 › 主题 › 我的配色主题
- 设置位置：歌词显示 › 悬浮歌词 › 文字 › 字体
- 设置位置：歌词显示 › 悬浮歌词 › 背景 › 毛玻璃背景

<a id="feature-karaoke"></a>

### 逐字卡拉OK效果

唱到哪个字亮到哪个字。悬浮歌词、灵动岛、菜单栏、触控栏和迷你歌词窗口各有一个开关，关掉就整句一起亮。

- 默认开启

## 播放器与播放控制

<a id="feature-players"></a>

### 九个播放器，可多选或自动识别

### 按需要的权限

## 全部设置项

设置窗口里的每一项，按所在位置列出，共 216 项。在设置窗口侧栏顶部的搜索框里输入名称，可以直接跳到那一项。

### 歌词 › 获取

- **歌词来源**
- **匹配算法**
- **随匹配算法更新重新选择**：开（默认）：匹配算法或评分规则更新后，会在后台重新评估已有歌词，并可能更换为更合适的版本；关：歌词确定后不再自动更换；首次解析、手动重新搜索和手动编辑不受影响
- **预解析待播曲目**
- **锁定手选歌词**：关（默认）：仅本次更换，之后的自动搜索或评分变化仍可能替换；开：锁定这首歌曲的歌词，自动匹配不再更改；开启时，之前手动选定的歌曲一并锁定（已被自动替换的除外）

### 歌词 › 译文

- **译文语言**：选择译文的语言。悬浮歌词、歌词窗口等是否显示译文，可在「歌词显示」中分别设置
- **系统兜底翻译**：歌词源未提供译文时补充
- **翻译语言包**：仅统计可翻译为当前译文语言的语言；译文语言本身及同一语系的语言不计入，因此数量可能少于「系统设置」中显示的数量。语言包由 macOS 管理，翻译在本机完成

### 歌词 › 调整

- **繁简转换**：将中文歌词统一显示为简体或繁体
- **标注读音的语言**：选择为哪些语言的歌词标注读音。悬浮歌词、歌词窗口等是否显示读音，可在「歌词显示」中分别设置
- **长句拆分**：在悬浮歌词、灵动岛、菜单栏和触控栏上，一行显示不下的句子会按各自宽度拆分为多段依次显示，不换行也不滚动；歌词窗口仍按一句一行显示
- **短句合并**：在悬浮歌词、灵动岛、菜单栏和触控栏上，连续的短句会合并为一句显示，仅在合并后能在一行内显示时合并；触控栏较宽，相邻几句能放下且合计不超过 5 秒即可合并；歌词窗口仍按一句一行显示
- **时间轴偏移**：正值：歌词提前；负值：歌词延后

### 歌词 › 管理

- **歌词库**
- **自动匹配缺失歌词**：自动匹配范围：无歌词或仅有纯文本的歌曲；纯音乐和人工修正过的歌曲除外
- **重新匹配整个歌词库**：已有歌词的歌曲也会重新匹配；人工修正、已校准时间轴和纯音乐的歌曲除外
- **歌词文件夹**：更换文件夹后，现有文件不会自动迁移

### 播放器

- **播放器**
- **网页播放器**：网页播放器不会主动报告精确进度，开启此选项可在切歌后立即校准。
