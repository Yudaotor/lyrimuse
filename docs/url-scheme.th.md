# รูปแบบ URL ของ Lyrimuse

*[English](url-scheme.md) · [简体中文](url-scheme.zh-CN.md) · [日本語](url-scheme.ja.md) · [한국어](url-scheme.ko.md) · [Español](url-scheme.es.md) · [Français](url-scheme.fr.md) · [Deutsch](url-scheme.de.md) · [Italiano](url-scheme.it.md) · [Português (Brasil)](url-scheme.pt-BR.md) · [Tiếng Việt](url-scheme.vi.md) · [Русский](url-scheme.ru.md) · [Українська](url-scheme.uk.md) · **ไทย***

ลิงก์ที่ขึ้นต้นด้วย `lyrimuse://` ใช้ควบคุม Lyrimuse จากคำสั่งลัด, Raycast, Alfred, Stream Deck, เทอร์มินัล (`open 'lyrimuse://…'`) และเครื่องมืออื่นๆ ในทำนองเดียวกันได้ ทั้งเปิดหน้าต่างและหน้าการตั้งค่า แสดงหรือซ่อนเนื้อเพลง ควบคุมการเล่น ขยับจังหวะเวลาของเนื้อเพลง หรือดึงข้อมูลเพลงที่กำลังเล่นอยู่

ลิงก์ที่ใช้บ่อยคัดลอกได้จาก **Deep link** ที่ด้านล่างของ การตั้งค่า › ปุ่มลัดแป้นพิมพ์ วางตัวชี้บนปุ่มลัดใดก็ได้ในหน้านั้นเพื่อคัดลอกลิงก์ของการทำงานนั้น

## กฎทั่วไป

- ลิงก์ไม่ยึดตามตัวพิมพ์ใหญ่-เล็ก
- ลิงก์ที่ Lyrimuse ไม่รู้จักจะไม่ทำอะไร และแสดง “ลิงก์ที่ไม่รู้จัก”
- ลิงก์ใดก็ตามที่เปิดหน้าต่างรับ `background=1` ได้ หน้าต่างจะปรากฏขึ้น แต่ Lyrimuse จะไม่ขึ้นมาอยู่ด้านหน้าและไม่รับโฟกัสแป้นพิมพ์ เช่น `lyrimuse://lyrics-window?background=1`
- การทำงานแบบเปิด/ปิดรับ `on=1` หรือ `on=0` เพื่อกำหนดสถานะที่ต้องการ (ใช้ `true` / `false` และ `on` / `off` ได้เช่นกัน) การเรียกใช้ซ้ำจึงได้ผลเหมือนเรียกครั้งเดียว หากไม่ระบุ จะสลับสถานะ
- หน้าเว็บก็เปิดลิงก์ `lyrimuse://` ได้เช่นกัน (เบราว์เซอร์จะถามก่อน) จึงเปิดให้ใช้เฉพาะการทำงานที่ย้อนกลับได้ง่าย ได้แก่ การเปิด/ปิด การเปิดหน้าต่าง การควบคุมการเล่น และการขยับจังหวะเวลา ไม่มีลิงก์ใดลบหรือแก้ไขเนื้อเพลง หรือแตะต้องบัญชีของคุณ

## การเปิดหน้าต่าง

| ลิงก์ | หน้าที่ |
|---|---|
| `lyrimuse://lyrics-window` | เปิดหน้าต่างเนื้อเพลง |
| `lyrimuse://lyrics-window/search` | เปิดหน้าต่างเนื้อเพลงและหน้าต่าง “ค้นหาเนื้อเพลง” (หน้าต่างเดียวกับที่ `lyrics-search` เปิด) |
| `lyrimuse://lyrics-manager` | เปิดตัวจัดการเนื้อเพลง |
| `lyrimuse://lyrics-search` | เปิดหน้าต่าง “ค้นหาเนื้อเพลง” สำหรับเพลงปัจจุบัน |
| `lyrimuse://menubar-panel` | เปิดหรือปิดแผงในแถบเมนู |
| `lyrimuse://menubar-panel?quick=overlay` | เปิดแผงในแถบเมนูที่การตั้งค่าด่วนของการ์ดหนึ่ง (เปิดอย่างเดียว ไม่ปิด) `quick` เป็นค่าใดค่าหนึ่งใน `overlay`, `notch`, `menubar`, `touchbar`, `lyrics-window`, `lyrics-manager` |
| `lyrimuse://menubar-menu` | แสดงเมนูของไอคอนในแถบเมนู |
| `lyrimuse://onboarding` | เปิดตัวช่วยตั้งค่า |
| `lyrimuse://whats-new` | แสดงว่ามีอะไรใหม่ในเวอร์ชั่นที่ติดตั้งอยู่ |

## การเปิดการตั้งค่า

`lyrimuse://settings` เปิดการตั้งค่า เพิ่มเส้นทางต่อท้ายเพื่อไปยังหน้าที่ต้องการโดยตรง และต่อท้ายอีก 1 ระดับเพื่อไปยังหัวข้อในหน้านั้น

| เส้นทาง | หน้า | หัวข้อ |
|---|---|---|
| `/lyrics` | เนื้อเพลง | `/fetch` หรือ `/sources` แหล่งที่มา, `/translation` หรือ `/language` ภาษา, `/display` หรือ `/timing` เวลาและการแบ่งวรรค, `/manage` หรือ `/library` คลังเนื้อเพลง |
| `/player` | เครื่องเล่น | `/players` เครื่องเล่น, `/linkage` เปิดและออก, `/permissions` สิทธิ์และบริการ |
| `/appearance` | การแสดงเนื้อเพลง | `/overlay` เนื้อเพลงแบบลอย, `/notch` รอยบาก, `/menu-bar` แถบเมนู, `/touch-bar` Touch Bar, `/lyrics-window` หน้าต่างเนื้อเพลง |
| `/shortcuts` | ปุ่มลัดแป้นพิมพ์ | — |
| `/general` | ทั่วไป | — |
| `/about` | เกี่ยวกับ | — |
| `/account/lastfm` | Last.fm | `/stats` สถิติ, `/chart` ชาร์ต, `/on-this-day` ย้อนรอย, `/settings` กฎ |
| `/account/listenbrainz` | ListenBrainz | — |
| `/account/discord` | Discord | `/display` สิ่งที่แสดง, `/buttons` ปุ่ม, `/privacy` ความเป็นส่วนตัว |
| `/account/relay` | พุชบนเว็บ | — |
| `/account/bark` | การแจ้งเตือนแบบพุช | — |
| `/software-update` | รายการอัปเดตซอฟต์แวร์ | เพิ่ม `?check=1` เพื่อตรวจหารายการอัปเดตไปด้วย |
| `/lastfm-suggestions` | คำแนะนำสำหรับบัญชี Last.fm | — |
| `/labs` | ทดลอง | — |

เช่น `lyrimuse://settings/appearance/overlay` หรือ `lyrimuse://settings/software-update?check=1` เส้นทางที่ไม่รู้จักจะเปิดแค่การตั้งค่า ส่วนหัวข้อที่ไม่รู้จักจะเปิดหน้านั้นที่หัวข้อที่ดูไว้ล่าสุด

## การทำงาน: `lyrimuse://action/<name>`

การทำงานเหล่านี้คือการทำงานเดียวกับปุ่มลัดใน การตั้งค่า › ปุ่มลัดแป้นพิมพ์ ใช้โค้ดเดียวกันและแสดงการตอบสนองแบบเดียวกัน

### การแสดงผล

| ชื่อ | หน้าที่ | พารามิเตอร์ |
|---|---|---|
| `toggle-overlay` | แสดงหรือซ่อนเนื้อเพลงแบบลอย | `on` |
| `toggle-notch` | แสดงหรือซ่อนเนื้อเพลงที่รอยบาก | `on` |
| `peek-notch` | ขยายเนื้อเพลงที่รอยบากไว้สองสามวินาที เรียกใช้อีกครั้งเพื่อปิดก่อนเวลา | — |
| `toggle-menubar-lyrics` | แสดงหรือซ่อนเนื้อเพลงในแถบเมนู | `on` |
| `toggle-touchbar` | ขยายหรือยุบเนื้อเพลงใน Touch Bar (เฉพาะ Mac ที่มี Touch Bar) | — |
| `toggle-all-lyrics` | ซ่อนเนื้อเพลงทั้งหมด: เนื้อเพลงแบบลอย เนื้อเพลงที่รอยบาก และเนื้อเพลงในแถบเมนู ตัวที่เปิดอยู่จะถูกซ่อน และเมื่อเรียกใช้อีกครั้งจะแสดงกลับมาเฉพาะตัวเหล่านั้น | `on` (`0` ซ่อน, `1` แสดงกลับมา) |
| `toggle-lock-position` | ล็อคหรือปลดล็อคตำแหน่งของเนื้อเพลงแบบลอย | `on` |
| `toggle-translation` | แสดงหรือซ่อนคำแปล | `on` |
| `toggle-romanization` | แสดงหรือซ่อนการออกเสียง | `on` |
| `overlay-font-larger` | ขยายเนื้อเพลงแบบลอยให้ใหญ่ขึ้น | — |
| `overlay-font-smaller` | ย่อเนื้อเพลงแบบลอยให้เล็กลง | — |

### การทำงานอื่นๆ

| ลิงก์ | หน้าที่ |
|---|---|
| `lyrimuse://action/copy-lyric` | คัดลอกบรรทัดเนื้อเพลงปัจจุบันไปยังคลิปบอร์ด เพิ่ม `?translation=1` เพื่อคัดลอกคำแปลไปด้วย |
| `lyrimuse://action/surfaces?overlay=1&notch=0&menubar=1` | กำหนดในครั้งเดียวว่าจะแสดงเนื้อเพลงแบบใดบ้าง: `overlay` (เนื้อเพลงแบบลอย), `notch`, `menubar` แต่ละตัวใช้ `1` เพื่อแสดงหรือ `0` เพื่อซ่อน ใส่เฉพาะตัวที่ต้องการเปลี่ยน |
| `lyrimuse://action/lyrics-offset?ms=-300` | ตั้งค่าการชดเชยเวลาเนื้อเพลงของเพลงนี้เป็นค่าที่แน่นอนในหน่วยมิลลิวินาที ค่าบวกคือเร็วขึ้น ค่าลบคือช้าลง ภายในช่วง ±10000 |
| `lyrimuse://action/play-mode?mode=shuffle` | ตั้งค่าโหมดการเล่น: `mode` เป็น `list`, `shuffle`, `repeat-all` หรือ `repeat-one` โหมดที่เครื่องเล่นไม่รองรับจะกลับไปใช้ `list` |

## ดึงข้อมูลเพลงที่กำลังเล่นอยู่ (x-callback-url)

```
lyrimuse://x-callback-url/now-playing?x-success=<callback URL>
```

Lyrimuse จะเปิด URL ใน `x-success` โดยเพิ่มข้อมูลเพลงที่กำลังเล่นอยู่เป็นพารามิเตอร์ (พารามิเตอร์ที่มีอยู่แล้วใน `x-success` จะยังคงอยู่):

| พารามิเตอร์ | ค่า |
|---|---|
| `title` | ชื่อเพลง |
| `artist` | ศิลปิน |
| `album` | อัลบั้ม |
| `lyric` | บรรทัดเนื้อเพลงปัจจุบัน |
| `player` | ชื่อเครื่องเล่น |
| `playing` | `1` ขณะที่มีเพลงเล่นอยู่, `0` เมื่อหยุดพักหรือไม่มีเพลงโหลดอยู่ (หากไม่มีเพลงโหลดอยู่ ช่องข้างต้นจะว่างเปล่า) |

ในคำสั่งลัด ให้ใช้การทำงาน **เปิด X-Callback URL** โดยใส่ `lyrimuse://x-callback-url/now-playing` เป็น URL คำสั่งลัดจะเพิ่ม `x-success` ให้เอง และพารามิเตอร์ที่ส่งกลับมาจะกลายเป็นผลลัพธ์ของการทำงานนั้น

เพื่อไม่ให้หน้าเว็บใช้ลิงก์นี้ดูว่าคุณกำลังฟังอะไรอยู่ URL เรียกกลับจึงมีข้อจำกัด 2 ข้อ คือต้องไม่ใช่ URL ของเว็บ ไฟล์ หรือสคริปต์ (`http`, `https`, `file`, `ftp`, `javascript`, `data`, `about`, `blob` หรือ `lyrimuse` เอง) และบน Mac ของคุณ ต้องเปิดโดยแอปที่ไม่ใช่เบราว์เซอร์ มิฉะนั้นจะไม่มีการส่งข้อมูลกลับ
