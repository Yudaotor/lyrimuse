# Lyrimuse 功能清單

[English](feature-list.md) · [简体中文](feature-list.zh-CN.md) · 繁體中文

Lyrimuse 是一款開源（GPL-3.0）的 macOS 逐字歌詞 App，支援 macOS 14 及以上版本，相容 Apple Silicon 和 Intel 晶片。它為 Apple Music、Spotify、QQ 音樂、網易雲音樂、酷狗音樂、汽水音樂、KKBOX、Amazon Music、洛雪音樂、Kaset、reAMP，以及瀏覽器中的 YouTube Music 和 Spotify 網頁版顯示逐字同步的歌詞：可顯示在桌面浮動歌詞、動態島、選單列、觸控列和歌詞視窗中，並提供譯文和讀音標註（拼音、粵拼、日文羅馬拼音、韓文羅馬字），還可將聆聽記錄打卡到 Last.fm 和 ListenBrainz，並在 Discord 上顯示正在聆聽的歌曲。介面支援簡體中文、繁體中文和英文。

這份清單列出 Lyrimuse 的每一項功能：做什麼、在設定的哪裡、安裝後預設開著還是關著；最後附上設定視窗裡的全部設定項目。清單跟程式碼一起維護，功能有增減時同步更新。

## 尋找歌詞

<a id="feature-lyric-sources"></a>

### 十五個歌詞來源自動查找

網易雲音樂、QQ 音樂、酷狗、酷我、咪咕、Musixmatch、LRCLIB、LyricFind、Deezer、AMLL、汽水音樂、VIBE、Genie、PetitLyrics 和 Apple Music。每個歌詞來源均可單獨開關、調整順序，或測試目前是否可連線。

- 預設開啟
- 設定位置：歌詞 › 取得 › 歌詞來源

<a id="feature-apple-music-lyrics"></a>

### Apple Music 官方歌詞

在「歌詞來源」中連線至 Apple Music 帳號後，即可使用 Apple Music 官方歌詞，多數歌曲帶逐字時間軸。需要 Apple Music 訂閱。

- 預設關閉
- 設定位置：歌詞 › 取得 › 歌詞來源

<a id="feature-matching"></a>

### 智慧比對

預設對各歌詞來源的結果評分，依歌名、歌手、時長和版本（現場版、伴奏等）選出與目前播放歌曲最吻合的一份。也可改為「順序優先」：不評分，依你設定的順序採用第一個有結果的歌詞來源。

- 設定位置：歌詞 › 取得 › 比對演算法

<a id="feature-auto-upgrade"></a>

### 比對規則更新後重新選擇

新版本改進比對演算法或評分規則後，在背景重新評估已有歌詞，有更合適的版本時自動替換。關閉後，歌詞一經選定不再自動更換。

- 預設開啟
- 設定位置：歌詞 › 取得 › 隨比對演算法更新重新選擇

<a id="feature-prefetch"></a>

### 預先取得後續歌曲的歌詞

讀取播放器的播放佇列，預先為接下來的幾首歌曲取得歌詞；無法讀取佇列時，優先取得同一專輯中的其他歌曲。QQ 音樂、網易雲音樂、酷狗音樂和汽水音樂的佇列需要「完整磁碟取用權限」才能讀取。

- 預設開啟
- 設定位置：歌詞 › 取得 › 預解析待播曲目
- 設定位置：播放器 › 權限與服務 › 完整磁碟取用權限

<a id="feature-player-local-lyrics"></a>

### 直接使用播放器儲存在本機的歌詞

QQ 音樂、網易雲音樂、酷狗音樂、KKBOX、Amazon Music 和洛雪音樂自己儲存的歌詞可直接使用，與播放器顯示的版本一致，速度也更快；reAMP 播放時使用檔案內嵌的歌詞或同名 .lrc 檔案。QQ 音樂、網易雲音樂、酷狗音樂需要在系統設定中為 Lyrimuse 開啟「完整磁碟取用權限」；未授權時仍可連線尋找歌詞。

- 預設關閉
- 設定位置：播放器 › 權限與服務 › 完整磁碟取用權限

<a id="feature-source-health"></a>

### 歌詞來源異常提醒

某個歌詞來源近期幾乎找不到歌詞、命中率明顯低於平時、頻繁出錯或無法連線時，「歌詞來源」中該來源旁會顯示提醒，按一下可查看判斷依據的次數和比例。其他歌詞來源照常搜尋，統計僅在本機進行。

- 設定位置：歌詞 › 取得 › 歌詞來源

<a id="feature-lock-hand-picked"></a>

### 鎖定手選歌詞

開啟後，從搜尋結果中手動選擇的歌詞將被鎖定，之後的自動比對和重新比對均不會替換。

- 預設關閉
- 設定位置：歌詞 › 取得 › 鎖定手選歌詞

<a id="feature-lyrics-manager"></a>

### 歌詞管理視窗

瀏覽、編輯、刪除或重新搜尋任意歌曲的歌詞，支援多選批次刪除，並可一次清理廣告和 Podcast 留下的空記錄。時間軸不準的歌曲可單獨調整偏移。尚無歌詞的歌曲可一鍵全部重試，整個歌詞庫也可依目前規則重新比對（每首之間的間隔可調），手動修改過的歌詞不受影響。

- 設定位置：歌詞 › 管理 › 歌詞庫
- 設定位置：歌詞 › 管理 › 自動比對缺少的歌詞
- 設定位置：歌詞 › 管理 › 重新比對整個歌詞庫
- 設定位置：快速鍵 › 打開歌詞管理
- 設定位置：歌詞 › 管理 › 掃描間隔

<a id="feature-song-entries"></a>

### 同曲條目：同一首歌曲共用歌詞

同一首歌在不同播放器、不同專輯版本中的條目會被辨識為同一首：各條目共用一份歌詞，手動修改和時間軸校正同步生效，播放次數合併統計。在歌詞管理中打開「同曲條目」可逐行對照各條目的歌詞，辨識有誤的條目可拆分，之後也可恢復合併。關閉共用後，各條目分別比對歌詞。

- 預設開啟
- 設定位置：歌詞 › 取得 › 同曲條目共用歌詞

<a id="feature-fix-lyrics"></a>

### 隨時更換、修改歌詞

在歌詞視窗的「⋯」選單中搜尋其他歌詞、重新自動比對，或在外部文字編輯器中修改。編輯逐字歌詞時只修改文字，每個字的時間保持不變。

- 設定位置：快速鍵 › 搜尋歌詞

<a id="feature-offline"></a>

### 離線可用，歌詞以 .lrc 檔案儲存

已找到的歌詞均快取在本機，離線時也能顯示。每首歌曲儲存一份 .lrc，有譯文、讀音時另存 .tr.lrc 和 .roma.lrc，逐字時間軸存為 .yrc。預設位於 ~/.config/lyrimuse/lyrics/，位置可更改。

- 設定位置：歌詞 › 管理 › 歌詞檔案夾

## 譯文、讀音與歌詞處理

<a id="feature-translation"></a>

### 譯文

歌詞來源內附的譯文顯示在原文下方。網易雲音樂、QQ 音樂、酷狗的譯文為中文；Musixmatch 和機器翻譯依所選譯文語言提供，共 17 種可選。浮動歌詞、歌詞視窗、動態島、選單列、觸控列可分別設定是否顯示。系統語言包含中文時預設顯示。

- 設定位置：歌詞 › 譯文 › 譯文語言
- 設定位置：歌詞顯示 › 浮動歌詞 › 內容 › 譯文
- 設定位置：快速鍵 › 顯示/隱藏譯文

<a id="feature-machine-translation"></a>

### 無譯文時自動翻譯

歌詞來源未提供譯文時使用機器翻譯。在 macOS 15 及以上且已下載翻譯語言包時，由 macOS 內建的 Apple 翻譯在本機完成，歌詞不離開本機；無法在本機翻譯時，將待翻譯的歌詞傳送至 Google 翻譯，仍不可用時改用 MyMemory。翻譯語言包可在同一張卡片中下載。

- 預設關閉
- 設定位置：歌詞 › 譯文 › 無譯文時自動翻譯
- 設定位置：歌詞 › 譯文 › 翻譯語言包

<a id="feature-romanization"></a>

### 讀音標註

日文羅馬拼音、韓文羅馬字、國語拼音、粵語粵拼，逐詞標註在歌詞上方。逐行判斷語言：中文歌曲中夾有一句日文時，只為該句標註。標註哪些語言可在此處選擇，中文介面預設不標註國語拼音。各顯示位置可分別設定是否顯示。

- 預設開啟
- 設定位置：歌詞 › 調整 › 標註讀音的語言
- 設定位置：歌詞顯示 › 浮動歌詞 › 內容 › 讀音
- 設定位置：快速鍵 › 顯示/隱藏讀音

<a id="feature-chinese-script"></a>

### 繁簡轉換

將中文歌詞統一顯示為簡體或繁體，與 App 介面語言無關。

- 設定位置：歌詞 › 調整 › 繁簡轉換

<a id="feature-split-join-lines"></a>

### 長句拆分、短句合併

浮動歌詞、動態島、選單列和觸控列依各自的可用寬度，將放不下的長句拆分為多句，將一閃而過的短句合併為一句。歌詞視窗仍依一句一行顯示。兩項各有獨立開關。

- 預設關閉
- 設定位置：歌詞 › 調整 › 長句拆分
- 設定位置：歌詞 › 調整 › 短句合併

<a id="feature-timing-offset"></a>

### 時間軸偏移

整體提前或延後歌詞，可僅對某個播放器生效。單首歌曲可在歌詞管理中單獨調整；也可透過快速鍵隨時提前、延後或歸零。

- 設定位置：歌詞 › 調整 › 時間軸偏移
- 設定位置：快速鍵 › 歌詞提前
- 設定位置：快速鍵 › 歌詞延後
- 設定位置：快速鍵 › 歌詞偏移歸零

## 歌詞顯示位置與外觀

<a id="feature-floating-lyrics"></a>

### 桌面浮動歌詞

浮於所有視窗之上、始終置頂的歌詞，逐字亮起。可拖移到任意位置，也可固定在螢幕頂部置中或 Dock 上方置中。連接多台顯示器時，可固定在其中一台，也可跟隨目前使用的視窗切換到其所在的顯示器。可同時顯示讀音、譯文和下一句。

- 預設開啟
- 設定位置：歌詞顯示 › 浮動歌詞 › 桌面浮動歌詞
- 設定位置：歌詞顯示 › 浮動歌詞 › 位置
- 設定位置：歌詞顯示 › 浮動歌詞 › 內容 › 下一句
- 設定位置：快速鍵 › 顯示/隱藏浮動歌詞
- 設定位置：歌詞顯示 › 浮動歌詞 › 所在螢幕

<a id="feature-notch-lyrics"></a>

### 動態島歌詞

緊貼螢幕頂部瀏海的膠囊，沒有瀏海的 Mac 和外接顯示器上同樣可用。左右兩側可分別顯示歌名、歌手、專輯、封面、播放控制、已播放或剩餘時長，旁邊是隨音樂跳動的音浪。指標指向時展開，提供播放控制、進度列、歌詞校正，以及喜歡、搜尋歌詞等快捷按鈕。播放廣告時顯示剩餘時長。

- 預設關閉
- 設定位置：歌詞顯示 › 動態島 › 動態島歌詞
- 設定位置：歌詞顯示 › 動態島 › 風格
- 設定位置：歌詞顯示 › 動態島 › 螢幕
- 設定位置：歌詞顯示 › 動態島 › 左耳
- 設定位置：快速鍵 › 顯示/隱藏動態島歌詞
- 設定位置：歌詞顯示 › 動態島 › 展開狀態 › 快速操作

<a id="feature-menu-bar-lyrics"></a>

### 選單列歌詞

目前歌詞直接顯示在選單列中，過長時捲動顯示，不會被截斷。可增加一行顯示下一句、譯文或讀音。

- 預設關閉
- 設定位置：歌詞顯示 › 選單列 › 選單列歌詞
- 設定位置：歌詞顯示 › 選單列 › 佈局 › 副行
- 設定位置：快速鍵 › 顯示/隱藏選單列歌詞

<a id="feature-touch-bar-lyrics"></a>

### 觸控列歌詞

在配備觸控列的 MacBook Pro 上，目前歌詞在觸控列上隨演唱位置捲動，還可顯示封面和播放控制。歌詞顏色可選白色、跟隨封面或自訂，未唱部分的亮度可調。可在開始播放時自動展開、暫停時自動收起；「更多」按鈕中提供歌詞校正、喜歡、隨機和循環、音量和播放進度。

## 播放器與播放控制

<a id="feature-players"></a>

### 十一款播放器，可多選或自動辨識

Apple Music、Spotify、QQ 音樂、網易雲音樂、酷狗音樂、汽水音樂、洛雪音樂、KKBOX、Amazon Music、仿 Winamp 的 reAMP，以及 YouTube Music 用戶端 Kaset。可同時選擇多個，也可保持自動辨識，跟隨 macOS「正在播放」中的播放器。支援 Apple Music 電台，主持人講話時顯示電台名稱和台標。

<a id="feature-web-players"></a>

### 瀏覽器中的 YouTube Music、Spotify 網頁版

### 依需求申請權限

Apple Music、Spotify 和 Kaset 需要「自動化」權限才能讀取播放狀態；QQ 音樂、網易雲音樂、酷狗音樂需要「完整磁碟取用權限」才能使用本機歌詞和播放佇列，汽水音樂需要該權限讀取播放佇列；Amazon Music 的進度校正，QQ 音樂、網易雲音樂、酷狗音樂、汽水音樂、Amazon Music 和 reAMP 的隨機、循環、喜歡按鈕，以及其他 App 佔用「正在播放」時 QQ 音樂、網易雲音樂和汽水音樂的播放按鈕，需要「輔助使用」權限；瀏覽器中的網頁播放器需要為瀏覽器開啟「自動化」權限，並在瀏覽器中開啟「允許 Apple 事件中的 JavaScript」。其他播放器無需權限。設定中會標明每項的目前授權狀態。

- 設定位置：播放器 › 權限與服務 › 完整磁碟取用權限
- 設定位置：播放器 › 權限與服務 › 輔助使用權限

<a id="feature-controls"></a>

### 播放控制與進度跳轉

在歌詞視窗和展開的動態島上播放、暫停、切歌，拖移進度列跳轉。隨機、循環、喜歡和音量取決於播放器的支援情況：Apple Music、Spotify、Kaset、QQ 音樂、Amazon Music 和瀏覽器中的 YouTube Music 支援其中部分或全部功能，網易雲音樂、酷狗音樂、汽水音樂和洛雪音樂支援喜歡，洛雪音樂在其設定中開啟開放 API 後還可調整音量。播放、暫停、切歌和喜歡也可設定全域快速鍵。瀏覽器影片等 App 佔用系統「正在播放」時，QQ 音樂、網易雲音樂和汽水音樂的播放、暫停和切歌改為透過其自身的選單或播放列操作，此時無法拖移進度跳轉。

- 設定位置：歌詞顯示 › 動態島 › 展開狀態 › 顯示播放控制
- 設定位置：快速鍵 › 播放/暫停

- 設定位置：播放器 › 權限與服務 › 洛雪音樂開放 API

## 聆聽記錄、Last.fm 與分享

<a id="feature-lastfm"></a>

### Last.fm 打卡與聆聽檔案

一鍵連線至 Last.fm，無需拷貝權杖。可查看今日、近 7 天和累計聆聽次數，歌手、專輯、歌曲排行榜及排名變化；「足跡」中提供全年熱度圖（按一下某一天可查看當天聆聽最多的歌曲）、聆聽時段、常聽歌手的國家和地區以及「那年今日」。最近播放中的每首歌曲都可按一下紅心標記喜歡。

- 預設關閉

<a id="feature-local-log"></a>

### 每次播放先記錄在本機

### 歌詞 › 取得

- **歌詞來源**
- **比對演算法**
- **隨比對演算法更新重新選擇**：開（預設）：比對演算法或評分規則更新後，會在背景重新評估已有歌詞，並可能更換為更合適的版本；關：歌詞確定後不再自動更換；首次解析、手動重新搜尋和手動編輯不受影響
- **同曲條目共用歌詞**：開（預設）：同一首歌在不同播放器、不同專輯版本下、可確認為同一錄音的條目使用同一份歌詞，手動修改一併同步；關：各條目分別比對歌詞，已同步的條目恢復為原來的歌詞
- **預解析待播曲目**
- **鎖定手選歌詞**：關（預設）：僅替換本次歌詞，之後的自動搜尋或評分變化仍可能再次替換；開：鎖定這首歌曲的歌詞，自動比對不再更改；開啟後，此前手動選定的歌曲一併鎖定（已被自動替換的除外）
