# Lyrimuse 機能一覧

[English](feature-list.md) · [简体中文](feature-list.zh-CN.md) · [繁體中文](feature-list.zh-Hant.md) · 日本語 · [한국어](feature-list.ko.md) · [Español](feature-list.es.md) · [Français](feature-list.fr.md) · [Deutsch](feature-list.de.md)

Lyrimuseは、オープンソース（GPL-3.0）のmacOS用の単語ごとの歌詞Appです。macOS 14以降に対応し、Apple SiliconとIntelのどちらでも動作します。Apple Music、Spotify、QQ Music、NetEase Cloud Music、Kugou、Soda Music、KKBOX、Amazon Music、LX Music、Kaset、reAMP、VOX、Pine Player、foobar2000、そしてブラウザで再生するYouTube MusicとSpotify Web版の歌詞を単語ごとに同期して、デスクトップのフローティング歌詞、ノッチ、メニューバー、Touch Bar、歌詞ウインドウに表示します。翻訳とローマ字表記（ピンイン、粤拼、日本語のローマ字、韓国語のローマ字）にも対応し、再生履歴をLast.fmとListenBrainzにScrobbleしたり、再生中の曲をDiscordに表示したりできます。インターフェイスは簡体字中国語、繁体字中国語、英語、日本語、韓国語、スペイン語、フランス語、ドイツ語に対応しています。

Lyrimuse のすべての機能について、何ができるか、設定のどこにあるか、インストール直後にオンかオフかをまとめています。最後に設定ウインドウの全項目を載せています。この一覧はコードと一緒に管理し、機能が増減するたびに更新します。

## 歌詞の検索

<a id="feature-lyric-sources"></a>

### 15の歌詞ソースを自動で検索

NetEase Cloud Music、QQ Music、Kugou、Kuwo、Migu、Musixmatch、LRCLIB、LyricFind、Deezer、AMLL、Soda Music、VIBE、Genie、PetitLyrics、Apple Music。歌詞ソースごとにオン/オフ、並べ替え、現在接続できるかのテストができます。

- 初期設定でオン
- 設定の場所：歌詞 › ソース › 歌詞ソース

<a id="feature-network-proxy"></a>

### 海外の歌詞ソースに接続できないときはプロキシ経由で再試行

海外の歌詞ソースに直接接続できない場合は、システムのプロキシや、このMacのClashなどのプロキシ経由で自動的に再試行します。プロキシサーバを手動で指定することも、プロキシを使用しないこともできます。中国国内の歌詞ソースには常に直接接続します。

- 初期設定でオン
- 設定の場所：一般 › ネットワーク › プロキシ

<a id="feature-apple-music-lyrics"></a>

### Apple Musicの公式歌詞

「歌詞ソース」でApple Musicアカウントに接続すると、Apple Musicの公式歌詞を使用できます。多くの曲に単語ごとのタイミングが付いています。Apple Musicのサブスクリプションが必要です。

- 初期設定でオフ
- 設定の場所：歌詞 › ソース › 歌詞ソース

<a id="feature-matching"></a>

### スマートマッチング

デフォルトでは各歌詞ソースの結果をスコア付けし、曲名、アーティスト、長さ、バージョン（ライブ、インストゥルメンタルなど）から再生中の曲に最も合うものを選びます。「優先順位」に切り替えると、スコア付けをせず、設定した順序で最初に歌詞が見つかったソースを使用します。

- 設定の場所：歌詞 › ソース › マッチングアルゴリズム

<a id="feature-auto-upgrade"></a>

### マッチングルールの更新後に再選択

新しいバージョンでマッチングアルゴリズムやスコアのルールが改善されると、既存の歌詞をバックグラウンドで再評価し、より適したものがあれば自動的に置き換えます。オフにすると、一度選ばれた歌詞は自動では変更されません。

- 初期設定でオン
- 設定の場所：歌詞 › ソース › アルゴリズム更新後に再選択

<a id="feature-prefetch"></a>

### 次の曲の歌詞を事前に取得

プレーヤーの再生キューを読み取り、次の数曲の歌詞を事前に取得します。キューを読み取れない場合は、同じアルバムのほかの曲を優先して取得します。QQ Music、NetEase Cloud Music、Kugou Music、Soda Music、VOXのキューを読み取るには「フルディスクアクセス」が必要です。

- 初期設定でオン
- 設定の場所：歌詞 › ソース › 再生予定の曲を先読み
- 設定の場所：プレーヤー › 権限とサービス › フルディスクアクセス

<a id="feature-player-local-lyrics"></a>

### プレーヤーがこのMacに保存した歌詞をそのまま使用

Apple Music、Spotify、Kugou Music、KKBOX、Amazon Music、LX MusicがこのMacに保存した歌詞はそのまま使用でき、プレーヤーに表示されるものと同じバージョンをより速く表示できます（Apple MusicとSpotifyは、プレーヤーで歌詞を表示したことのある曲のみ）。QQ MusicとNetEase Cloud Musicでは、ローカルのライブラリから再生中の曲を識別するため、検索せずに同じバージョンの歌詞を取得できます。reAMP、VOX、Pine Player、foobar2000で再生するときや、Apple Musicでライブラリ内のローカルファイルを、LX Musicでローカルリストの曲を再生するときは、ファイルに埋め込まれた歌詞または同じ名前の.lrcファイルを使用します。QQ Music、NetEase Cloud Music、Kugou Musicでは、システム設定でLyrimuseに「フルディスクアクセス」を許可する必要があります。許可しなくてもオンラインで歌詞を検索できます。

- 初期設定でオフ
- 設定の場所：プレーヤー › 権限とサービス › フルディスクアクセス

<a id="feature-prefer-local-file-lyrics"></a>

### 曲ファイルの歌詞を優先

このMacの音楽ファイルを再生するときは、同じ名前の.lrcまたはファイルに埋め込まれた歌詞を優先して使い、オンラインで見つかった歌詞とは比較しません。プレーヤーを問わず、ローカルファイルを再生していれば有効です。歌詞がこのバージョンと合わない場合（長さが一致しないなど）は、通常どおりオンラインで検索します。

- 初期設定でオフ
- 設定の場所：歌詞 › ソース › 曲ファイルの歌詞を優先

<a id="feature-lock-hand-picked"></a>

### 手動で選んだ歌詞をロック

オンにすると、検索結果から手動で選んだ歌詞がロックされ、以降の自動マッチングや再照合で置き換えられることはありません。

- 初期設定でオフ
- 設定の場所：歌詞 › ソース › 手動で選んだ歌詞をロック

<a id="feature-lyrics-manager"></a>

### 歌詞マネージャ

任意の曲の歌詞を閲覧、編集、削除、再検索できます。複数選択して一括削除したり、広告やポッドキャストが残した空の項目をまとめてクリーンアップしたりもできます。タイミングがずれている曲は個別にオフセットを調整できます。歌詞がまだない曲はワンクリックですべて再試行でき、歌詞ライブラリ全体を現在のルールで再照合することもできます（曲ごとの間隔は調整可能）。手動で編集した歌詞は影響を受けません。

- 設定の場所：歌詞 › 歌詞ライブラリ › 歌詞ライブラリ
- 設定の場所：歌詞 › 歌詞ライブラリ › 見つからない歌詞を自動マッチング
- 設定の場所：歌詞 › 歌詞ライブラリ › 歌詞ライブラリ全体を再照合
- 設定の場所：キーボードショートカット › 歌詞マネージャを開く
- 設定の場所：歌詞 › 歌詞ライブラリ › スキャン間隔

<a id="feature-song-entries"></a>

### 同じ曲のエントリ：同じ曲で歌詞を共有

異なるプレーヤーや異なるアルバムのバージョンにある同じ曲のエントリは、同じ曲として識別されます。各エントリは1つの歌詞を共有し、手動の編集やタイミングの補正も共通で反映され、再生回数は合算されます。歌詞マネージャで「同じ曲のエントリ」を開くと各エントリの歌詞を行ごとに比較でき、誤って識別されたエントリは分割して、あとで再び結合することもできます。共有をオフにすると、各エントリの歌詞は個別にマッチングされます。

- 初期設定でオン
- 設定の場所：歌詞 › ソース › 同じ曲の項目で歌詞を共有

<a id="feature-fix-lyrics"></a>

### 歌詞をいつでも差し替え・修正

歌詞ウインドウの「⋯」メニューから、ほかの歌詞を検索したり、自動で再照合したり、外部のテキストエディタで編集したりできます。単語ごとの歌詞を編集しても変わるのは文字だけで、各単語のタイミングは保持されます。

- 設定の場所：キーボードショートカット › 歌詞を検索

<a id="feature-import-lyrics"></a>

### 手持ちの歌詞ファイルを読み込む

1曲ずつ、またはフォルダごとまとめて、LRC、拡張LRC、TTML、QRC、KRC、YRC、プレーンテキストの歌詞を読み込めます。ファイルは歌詞ライブラリの曲に対応付けられ、書き込む前にプレビューで確認できます。今の歌詞を置き換えるか、置き換えてロックするか、歌詞のない曲だけに使うかを選べます。まだ再生していない曲の歌詞ファイルは保存され、初めて再生したときに使われます。監視フォルダを設定すると、新しく入れたファイルが自動で読み込まれます。

- 設定の場所：歌詞 › 歌詞ライブラリ › 歌詞フォルダを読み込む
- 設定の場所：歌詞 › 歌詞ライブラリ › フォルダの読み込み方法
- 設定の場所：歌詞 › 歌詞ライブラリ › 監視フォルダ
- 設定の場所：歌詞 › 歌詞ライブラリ › 読み込みライブラリ

<a id="feature-offline"></a>

### オフラインで使用可能、歌詞は.lrcファイルで保存

見つかった歌詞はすべてこのMacにキャッシュされ、オフラインでも表示できます。曲ごとに.lrcファイルを1つ保存し、翻訳やローマ字がある場合は.tr.lrcと.roma.lrcも保存します。単語のタイミングはデフォルトでTTMLとして保存され、.yrc、拡張LRC、QRC、KRCに変更することもできます。デフォルトの保存場所は~/Library/Application Support/me.yudaotor.lyrimuse/lyrics/で、変更することもできます。

- 設定の場所：歌詞 › 歌詞ライブラリ › 歌詞フォルダ
- 設定の場所：歌詞 › 歌詞ライブラリ › 単語ごとの歌詞のフォーマット

## 翻訳、ローマ字表記と歌詞の処理

<a id="feature-translation"></a>

### 翻訳

歌詞ソースに付属する翻訳は原文の下に表示されます。NetEase Cloud Music、QQ Music、Kugouの翻訳は中国語です。Musixmatchと機械翻訳は、選択した翻訳の言語（17言語から選択可能）で提供されます。フローティング歌詞、歌詞ウインドウ、ノッチ、メニューバー、Touch Barで、それぞれ表示するかどうかを設定できます。システムの言語に中国語が含まれている場合はデフォルトで表示されます。

- 設定の場所：歌詞 › 言語 › 翻訳の言語
- 設定の場所：歌詞の表示 › フローティング歌詞 › 内容 › 翻訳
- 設定の場所：キーボードショートカット › 翻訳を表示/非表示

<a id="feature-machine-translation"></a>

### 翻訳がない場合は自動で翻訳

歌詞ソースが翻訳を提供していない場合は機械翻訳を使用します。macOS 15以降で翻訳の言語をダウンロード済みであれば、macOS標準のApple翻訳がこのMac上で翻訳するため、歌詞がこのMacの外に出ることはありません。このMacで翻訳できない場合は翻訳する歌詞をGoogle翻訳に送信し、それも使えない場合はMyMemoryを使用します。翻訳の言語は同じカードからダウンロードできます。

- 初期設定でオフ
- 設定の場所：歌詞 › 言語 › 翻訳がない場合に自動で翻訳
- 設定の場所：歌詞 › 言語 › 翻訳の言語

<a id="feature-romanization"></a>

### ローマ字表記

日本語のローマ字、韓国語のローマ字、標準中国語のピンイン、広東語の粤拼を、単語ごとに歌詞の上に表示します。ロシア語、タイ語、ギリシャ語、ヒンディー語など18言語は、各言語の公式な方式またはISO規格で表記します。言語は行ごとに判定されるため、中国語の曲に日本語の行が1つ混ざっている場合は、その行だけに表示されます。表示する言語はここで選択でき、中国語のインターフェイスではピンインはデフォルトでオフです。表示場所ごとに表示するかどうかを設定できます。

- 初期設定でオン
- 設定の場所：歌詞 › 言語 › ローマ字を付ける言語
- 設定の場所：歌詞 › 言語 › 日本語の読み
- 設定の場所：歌詞の表示 › フローティング歌詞 › 内容 › ローマ字
- 設定の場所：キーボードショートカット › ローマ字を表示/非表示

<a id="feature-chinese-script"></a>

### 簡体字・繁体字の変換

中国語の歌詞をすべて簡体字または繁体字で表示します。Appのインターフェイスの言語とは関係ありません。

### 再生コントロールとシーク

## 再生履歴、Last.fmと共有

<a id="feature-lastfm"></a>

### Last.fmのScrobbleとリスニングプロフィール

ワンクリックでLast.fmに接続でき、トークンをコピーする必要はありません。今日、過去7日間、累計の再生回数や、アーティスト、アルバム、曲のランキングと順位の変動を確認できます。「足跡」では、1年分のヒートマップ（日付をクリックするとその日に最も再生した曲を表示）、再生時間帯、よく聴くアーティストの国と地域、「過去のこの日」を確認できます。最近再生した曲は、それぞれハートをクリックしてLoveできます。

- 初期設定でオフ
- 設定の場所：Last.fm › ルール › Scrobbleのルール

<a id="feature-scrobble-rules"></a>

### Scrobbleのカスタムルール

50%、75%、90%まで再生したとき、または最後まで再生したときに1回とカウントするよう設定できます。30秒未満の曲をカウントするかどうかも設定できます。デフォルトでは共演アーティストの表記、簡体字・繁体字の表記、「- Single」などの接尾辞をLast.fmの正式な項目に合わせますが、そのまま送信することもできます。特定のプレーヤーをLast.fmの対象から丸ごと除外することもできます。

- 設定の場所：Last.fm › ルール › Scrobbleのタイミング
- 設定の場所：Last.fm › ルール › 30秒未満の曲をScrobble
- 設定の場所：Last.fm › ルール › マッチングモード
- 設定の場所：Last.fm › ルール › Scrobbleするプレーヤー

<a id="feature-local-log"></a>

### すべての再生をまずこのMacに記録

Last.fmに接続していない間、再生履歴はまずこのMacに保存されます。接続後、Last.fmページの「未送信のScrobble」で「後から送信」をクリックするとアップロードできます。接続中に送信できなかった可能性のある記録は、自動的にLast.fmと照合して送信し直します。Last.fmが受け付けるのは約2週間以内の再生履歴のみです。

<a id="feature-listenbrainz"></a>

### ListenBrainzに同期

再生ごとに、同じ再生状態をもとにLast.fmとListenBrainzにそれぞれ送信するため、両方の記録が一致します。iPhoneからLast.fmに記録された再生をListenBrainzに読み込むこともできます。サイドバーの「ラボ」にあります。

- 初期設定でオフ
- 設定の場所：ラボ › ListenBrainz › アカウント情報

設定ウインドウの全項目を場所ごとに並べています。全部で 309 項目です。設定ウインドウのサイドバー上部の検索欄に名前を入力すると、その項目へ直接移動できます。

### 歌詞 › ソース

- **歌詞ソース**
- **マッチングアルゴリズム**
- **曲ファイルの歌詞を優先**：ローカルファイルを再生するとき、同じ名前の.lrcまたはファイルに埋め込まれた歌詞を優先して使用します
- **アルゴリズム更新後に再選択**：バックグラウンドで再評価し、より適したバージョンに置き換えることがあります
- **同じ曲の項目で歌詞を共有**：同じ録音にはプレーヤーやアルバムのバージョンを問わず1つの歌詞を共有し、手動での編集も同期されます
- **手動で選んだ歌詞をロック**：手動で選択した歌詞は自動マッチングで置き換えられません
- **再生予定の曲を先読み**：これから再生される曲の歌詞を事前に取得します

- **翻訳の言語**
- **翻訳がない場合に自動で翻訳**：まずこのMacで翻訳し、できない場合はオンラインで翻訳します

- **長い行を分割**：1行に収まらない場合は、複数に分割して順に表示します
- **短い行を結合**：隣り合う短い行が1行に収まる場合は結合して表示します
- **タイミングのオフセット**：正の値で歌詞が早く、負の値で遅く表示されます

### 歌詞 › 歌詞ライブラリ

- **歌詞ライブラリ**
- **見つからない歌詞を自動マッチング**：歌詞がない曲、またはテキストのみの歌詞の曲だけを検索します
- **歌詞ライブラリ全体を再照合**：歌詞がある曲も含みます。手動で修正した曲、タイミング調整済みの曲、インストゥルメンタルは除きます
- **スキャン間隔**：曲ごとの間隔（秒）です。レート制限を避けるため、2秒以上をおすすめします
- **歌詞フォルダ**：場所を変更しても、既存のファイルは移動しません
- **単語ごとの歌詞のフォーマット**
- **歌詞フォルダを読み込む**：フォルダ内の歌詞ファイルをライブラリの曲に対応させます。読み込む前にプレビューできます
- **フォルダの読み込み方法**
- **監視フォルダ**：フォルダに追加・変更された歌詞ファイルは自動で読み込まれます。歌詞のない曲にはすぐに追加し、歌詞のある曲は変更しません
- **読み込みライブラリ**：読み込んだ歌詞の表示と削除

### Discord

- **Discordに表示**：オンにすると、Discordのプロフィールとフレンドリストに再生中の曲が表示されます。フレンドに表示されない場合は、Discordの「ユーザー設定 › アクティビティのプライバシー」でアクティビティステータスの共有をオンにしてください
- **表示内容**
- **「再生中」の後に表示**：プロフィールの「××を再生中」の××の部分です。iOS版とWeb版のDiscordではこの設定は無視され、プレーヤー名が表示されます。曲名またはアーティストを選ぶと、ユーザ名の下の表示で「プレーヤー」を選べなくなります
- **ユーザー名の下に表示**：Discordでユーザ名の下に表示できるのは、1行目、2行目、または「再生中」の後の内容のみです。曲名とアーティストがどちらもこれらの位置にない場合、該当するオプションは使用できません
- **アートワークのバッジ**
- **一時停止後**
- **曲の情報**
- **ステータステキスト**
- **アートワークと進行状況**
- **アーティストとアルバムに接頭辞を付ける**：アーティストの前に「アーティスト：」、アルバムの前に「アルバム：」を付けます。曲名とアーティストが同じ行にある場合は付けません
- **ボタン**
- **カスタムボタン**

- **曲の詳細を隠す**：使用中のプレーヤーと再生状況のみを表示します。曲名、アーティスト、アルバム、歌詞、リンク、「プレーヤーで聴く」ボタンは送信されません
- **進行状況バーを表示**：オフにすると進行状況バーは表示されず、Discordには経過時間が表示されます。この経過時間は非表示にできません
