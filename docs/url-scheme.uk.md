# URL-схема Lyrimuse

*[English](url-scheme.md) · [简体中文](url-scheme.zh-CN.md) · [日本語](url-scheme.ja.md) · [한국어](url-scheme.ko.md) · [Español](url-scheme.es.md) · [Français](url-scheme.fr.md) · [Deutsch](url-scheme.de.md) · [Italiano](url-scheme.it.md) · [Português (Brasil)](url-scheme.pt-BR.md) · [Tiếng Việt](url-scheme.vi.md) · [Русский](url-scheme.ru.md) · **Українська***

Посилання, що починаються з `lyrimuse://`, дають змогу керувати Lyrimuse з програми «Швидкі команди», з Raycast, Alfred, Stream Deck, Термінала (`open 'lyrimuse://…'`) і подібних інструментів: відкривати вікна й сторінки параметрів, показувати чи ховати текст, керувати відтворенням, зсувати таймінг або дізнаватися, що зараз грає.

Найуживаніші посилання можна скопіювати в розділі **Deep links** унизу сторінки Параметри › Клавіатурні скорочення. Наведіть там вказівник на будь-яке скорочення, щоб скопіювати посилання для цієї дії.

## Загальні правила

- Регістр літер у посиланнях не має значення.
- Посилання, яке Lyrimuse не розпізнає, нічого не робить і показує «Нерозпізнане посилання».
- Будь-яке посилання, що відкриває вікно, приймає `background=1`: вікно зʼявляється, але Lyrimuse не виходить на передній план і не забирає фокус клавіатури. Наприклад, `lyrimuse://lyrics-window?background=1`.
- Дії-перемикачі приймають `on=1` або `on=0`, щоб задати потрібний стан (також працюють `true` / `false` і `on` / `off`), тож повторний запуск дає той самий результат. Без цього параметра вони просто перемикають стан.
- Посилання `lyrimuse://` можуть відкривати й вебсторінки (браузер спершу запитає вас), тому доступні лише дії, які легко скасувати: перемикачі, відкриття вікон, керування відтворенням і зсув таймінгу. Жодна дія не видаляє й не редагує тексти та не чіпає ваших облікових записів.

## Відкриття вікон

| Посилання | Що робить |
|---|---|
| `lyrimuse://lyrics-window` | Відкриває вікно тексту |
| `lyrimuse://lyrics-window/search` | Відкриває вікно тексту й вікно «Шукати текст» (те саме, що й `lyrics-search`) |
| `lyrimuse://lyrics-manager` | Відкриває менеджер текстів |
| `lyrimuse://lyrics-search` | Відкриває вікно «Шукати текст» для поточної пісні |
| `lyrimuse://menubar-panel` | Відкриває або закриває панель на смузі меню |
| `lyrimuse://menubar-panel?quick=overlay` | Відкриває панель на смузі меню одразу на швидких параметрах однієї плитки (лише відкриває, ніколи не закриває). `quick` — одне зі значень `overlay`, `notch`, `menubar`, `touchbar`, `lyrics-window`, `lyrics-manager` |
| `lyrimuse://menubar-menu` | Показує меню значка на смузі меню |
| `lyrimuse://onboarding` | Відкриває помічника початкового налаштування |
| `lyrimuse://whats-new` | Показує, що нового в інстальованій версії |

## Відкриття параметрів

`lyrimuse://settings` відкриває Параметри. Додайте шлях, щоб перейти просто на потрібну сторінку, і ще один сегмент, щоб перейти до розділу на цій сторінці.

| Шлях | Сторінка | Розділи |
|---|---|---|
| `/lyrics` | Текст | `/fetch` або `/sources` Джерело, `/translation` або `/language` Мова, `/display` або `/timing` Таймінг, `/manage` або `/library` Бібліотека текстів |
| `/player` | Програвач | `/players` Програвач, `/linkage` Запуск і завершення, `/permissions` Дозволи й служби |
| `/appearance` | Показ тексту | `/overlay` Плаваючий текст, `/notch` Виріз, `/menu-bar` Смуга меню, `/touch-bar` Touch Bar, `/lyrics-window` Вікно тексту |
| `/shortcuts` | Клавіатурні скорочення | — |
| `/general` | Загальні | — |
| `/about` | Про програму | — |
| `/account/lastfm` | Last.fm | `/stats` Статистика, `/chart` Чарти, `/on-this-day` Хроніка, `/settings` Правила |
| `/account/listenbrainz` | ListenBrainz | — |
| `/account/discord` | Discord | `/display` Що показувати, `/buttons` Кнопки, `/privacy` Приватність |
| `/account/relay` | Веб-push | — |
| `/account/bark` | Push-сповіщення | — |
| `/software-update` | Оновлення ПЗ | Додайте `?check=1`, щоб одразу перевірити наявність оновлень |
| `/lastfm-suggestions` | Пропозиції для облікового запису Last.fm | — |
| `/labs` | Лабораторія | — |

Наприклад, `lyrimuse://settings/appearance/overlay` або `lyrimuse://settings/software-update?check=1`. Невідомий шлях просто відкриває Параметри; невідомий розділ відкриває сторінку на тому розділі, який ви переглядали останнім.

## Дії: `lyrimuse://action/<name>`

Це ті самі дії, що й клавіатурні скорочення в розділі Параметри › Клавіатурні скорочення. Вони виконують той самий код і показують той самий відгук.

### Показ

| Назва | Що робить | Параметри |
|---|---|---|
| `toggle-overlay` | Показує або ховає плаваючий текст | `on` |
| `toggle-notch` | Показує або ховає текст у вирізі | `on` |
| `peek-notch` | Розгортає текст у вирізі на кілька секунд; повторний запуск згортає його раніше | — |
| `toggle-menubar-lyrics` | Показує або ховає текст на смузі меню | `on` |
| `toggle-touchbar` | Розгортає або згортає текст на Touch Bar (лише на Mac із Touch Bar) | — |
| `toggle-all-lyrics` | Ховає весь текст: з плаваючого тексту, тексту у вирізі й тексту на смузі меню ховається все, що ввімкнено, а повторний запуск повертає саме те, що було сховано | `on` (`0` ховає, `1` повертає) |
| `toggle-lock-position` | Фіксує або звільняє позицію плаваючого тексту | `on` |
| `toggle-translation` | Показує або ховає переклад | `on` |
| `toggle-romanization` | Показує або ховає вимову | `on` |
| `overlay-font-larger` | Збільшує плаваючий текст | — |
| `overlay-font-smaller` | Зменшує плаваючий текст | — |

### Вікна

| Назва | Що робить | Параметри |
|---|---|---|
| `open-lyrics-manager` | Відкриває менеджер текстів | — |
| `open-lyrics-window` | Відкриває вікно тексту | — |
| `toggle-lyrics-window-mini` | Перемикає вікно тексту між розмірами «Міні» й «Повний»; якщо вікно закрите, відкриває його в розмірі «Міні» | `on` (`1` «Міні», `0` «Повний») |
| `search-lyrics` | Відкриває вікно «Шукати текст» | — |
| `open-settings` | Відкриває Параметри | — |
| `open-player` | Виводить на передній план програвач, яким ви користуєтеся | — |
| `toggle-menubar-panel` | Відкриває або закриває панель на смузі меню, як клацання значка на смузі меню | — |

### Таймінг тексту

| Назва | Що робить | Параметри |
|---|---|---|
| `lyrics-advance` | Зсуває текст цієї пісні на один крок раніше | `step`: кількість секунд для цього зсуву (від 0 до 5); якщо не вказано, береться крок із Параметрів |
| `lyrics-delay` | Зсуває текст цієї пісні на один крок пізніше | `step`, як вище |
| `lyrics-offset-reset` | Скидає зсув тексту цієї пісні до нуля | — |

### Відтворення

| Назва | Що робить | Параметри |
|---|---|---|
| `play-pause` | Відтворення/пауза | — |
| `next-track` | Наступний трек | — |
| `previous-track` | Попередній трек | — |
| `toggle-favorite` | Додає поточну пісню до Улюблених або вилучає її звідти (якщо програвач це підтримує) | `on` (`1` додати, `0` вилучити) |

Наприклад, `lyrimuse://action/toggle-overlay?on=0` або `lyrimuse://action/lyrics-advance?step=0.5`.

### Інші дії

| Посилання | Що робить |
|---|---|
| `lyrimuse://action/copy-lyric` | Копіює поточний рядок тексту в буфер обміну; додайте `?translation=1`, щоб скопіювати й переклад |
| `lyrimuse://action/surfaces?overlay=1&notch=0&menubar=1` | Задає за один раз, який текст показувати: `overlay` (плаваючий текст), `notch`, `menubar`, кожен зі значенням `1`, щоб показати, або `0`, щоб сховати. Вказуйте лише ті, які хочете змінити |
| `lyrimuse://action/lyrics-offset?ms=-300` | Задає точне значення зсуву тексту цієї пісні в мілісекундах: додатне — раніше, відʼємне — пізніше, у межах ±10 000 |
| `lyrimuse://action/play-mode?mode=shuffle` | Задає режим відтворення: `mode` — це `list`, `shuffle`, `repeat-all` або `repeat-one`. Режими, яких програвач не підтримує, замінюються на `list` |

## Дані про поточний трек (x-callback-url)

```
lyrimuse://x-callback-url/now-playing?x-success=<callback URL>
```

Lyrimuse відкриває URL-адресу з `x-success`, додавши до неї як параметри дані про те, що зараз грає (параметри, які вже є в `x-success`, зберігаються):

| Параметр | Значення |
|---|---|
| `title` | Назва пісні |
| `artist` | Виконавець |
| `album` | Альбом |
| `lyric` | Поточний рядок тексту |
| `player` | Назва програвача |
| `playing` | `1`, коли щось відтворюється, `0` на паузі або коли нічого не завантажено (якщо нічого не завантажено, поля вище порожні) |

У програмі «Швидкі команди» скористайтеся дією **Відкрити URL-адресу X-Callback**, указавши як URL-адресу `lyrimuse://x-callback-url/now-playing`. «Швидкі команди» самі додають `x-success`, а повернуті параметри стають результатом дії.

Щоб вебсторінки не могли через це посилання дізнатися, що ви слухаєте, для URL-адреси зворотного виклику діють два обмеження: це не може бути вебадреса, адреса файлу чи сценарію (`http`, `https`, `file`, `ftp`, `javascript`, `data`, `about`, `blob` або сам `lyrimuse`), і на вашому Mac її має відкривати програма, яка не є браузером. Інакше нічого не повертається.
